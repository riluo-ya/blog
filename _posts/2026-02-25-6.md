***一切均在[Termux](https://termux.dev/cn/)中完成，可能需要加速器***

## 自动安装
```bash
curl -LO https://riluo-ya.github.io/blog/sh/Phira-mp/install.sh && bash install.sh
```

## 手动安装
### 更新软件源

```bash
pkg update && pkg upgrade -y
```

## 安装Node.js，pnpm，Git

```bash
node -v && pkg install nodejs-lts && pkg install git
```

## 克隆[tphira-mp项目](https://github.com/Pimeng/tphira-mp)并进入项目文件夹

>该过程可能需要加速器，当然你也可以用镜像站下载，这里不做推荐

```bash
git clone https://github.com/Pimeng/tphira-mp.git && cd tphira-mp
```

## 把server_config.example.yml文件复制并命名一份为server_config.yml

```bash
cp server_config.example.yml server_config.yml
```

## 构建项目

```bash
pnpm run build
```


## 启动项目

```bash
pnpm start
```

## 以指定语言启动项目
这里以中文为例
```bash
LANG=zh-CN pnpm start
```

## 修改配置文件
详见**server_config.yml**文件，保存后直接运行即可，无需重新编译
