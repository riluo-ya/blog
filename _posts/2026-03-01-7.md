# 软件准备
## 下载ZeroTermux
渠道一 [ZeroTermux官网](https://zerotermux.dev/)

![ztReleases下载](/assets/20260225/2.jpg)

![zt省电策略](/assets/20260225/3.jpg)

# 安装工具
## 换源
切换清华源
打开ZeroTermux 阅读协议给予权限
**点按音量+**或者**双击最左侧**屏幕唤出侧边栏
打开**常用功能**选择**切换源**点击**清华源**
![切换清华源](/assets/20260225/10.jpg)
在运行过程中会出现类似于
**Do you want to continue? [Y/n]**
的内容，请按下回车即可 可能会有数次

## 下载proot容器
```bash
pkg install proot-distro
```

## 安装Debian
```bash
proot-distro install debian
```

## 进入Debian
```bash
proot-distro login debian
```

## 更新软件源
```bash
apt update
```

## 安装工具
```bash
apt install -y nano wget screenfetch tar
```

## 下载dotnet安装脚本
```bash
wget https://dot.net/v1/dotnet-install.sh -O dotnet-install.sh
```

## 提权
```bash
chmod +x ./dotnet-install.sh
```

## 安装dotnet运行时
```bash
./dotnet-install.sh --version 8.0.13 --runtime aspnetcore
```

## 修改环境变量
```bash
nano $HOME/.bashrc
export PATH=$PATH:/root/.dotnet
export DOTNET_GCHeapHardLimit=3C0000000
```
> 3C0000000视设备情况而定，我的骁龙8Gen3绰绰有余

## 创建文件夹
```bash
mkdir as
```

## 进入文件夹
```bash
cd as
```

## 安装IC库
```bash
apt install -y libicu-dev
```

## 下载解包工具
```bash
wget https://github.com/FrandreJoestar/AssetStudioMod/releases/download/fixed/AssetStudioModCLI.zip
```

## 解压
```bash
unzip AssetStudioModCLI.zip
```

## 增加交换空间（可选）
> 若出现
> GC heap initialization failed with error 0x8007000E
> Failed to create CoreCLR, HRESULT: 0x8007000E
> 报错
> 可以使用下面命令更改交换空间
> ```bash
> export DOTNET_GCHeapHardLimit=536870912
> ```

## 解包
```bash
dotnet AssetStudioModCLI.dll [apk路径] -t [类型] -g type -o [输出目录] --log-output file 
```

这里以Phigros为例
apk路径为**/storage/emulated/0/MT2/apks/Phigros_3.18.3.apk**
输出目录为**/storage/emulated/0/MT2/apks//storage/emulated/0/MT2/apks/_export**
类型为**tex2d,sprite,textAsset,audio,**
则在***Debian中***运行
```bash
dotnet AssetStudioModCLI.dll /storage/emulated/0/MT2/apks//storage/emulated/0/MT2/apks/ -m export -g type --log-output file -o /storage/emulated/0/MT2/apks//storage/emulated/0/MT2/apks/_export -t tex2d,sprite,textAsset,audio,video
```
