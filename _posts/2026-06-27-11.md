>本次使用的是TRSS Yunzai
>部分场景可能需要加速器

## 安装NapCat

```bash
curl -o napcat.termux.sh https://nclatest.znin.net/NapNeko/NapCat-Installer/main/script/install.termux.sh && bash napcat.termux.sh
```

如果您已安装Yunzai了请删除**.bashrc**文件后重启Termux再执行上述命令

## 配置.bashrc文件

新建**.bashrc**文件，内容如下

```bash
# ===== 启动选择菜单 =====
# 仅在交互式 shell 中生效
if [[ $- == *i* ]]; then
    clear
    echo "=============================="
    echo "  请选择要启动的程序"
    echo "=============================="
    echo "  1) 启动 Yunzai"
    echo "  2) 启动 NapCat"
    echo "  0) 跳过，直接进入 Bash"
    echo "=============================="
    read -p "请输入选项: " choice

    case "$choice" in
        1)
            echo "正在启动 Yunzai..."
            exec '/data/data/com.termux/files/home/Arch/start' -c 'tsab;bash'
            ;;
        2)
            echo "正在启动 NapCat..."
            proot-distro sh napcat -- bash -c "xvfb-run -a /root/Napcat/opt/QQ/qq --no-sandbox"
            ;;
        0|*)
            echo "进入普通 Bash 终端"
            ;;
    esac
fi

```

## 登录NapCat
打开Termux后输入**2**启动 NapCat

在控制台找到**[WebUi]**复制后面的链接，到浏览器打开
![WebUi](1.jpg)

在webui界面选择登录方式
![登录方式](2.jpg)
我这里用二维码扫码登录

登录成功之后在侧边栏选择**系统配置**
![系统配置](3.jpg)

在顶栏选择**登录配置**
![登录配置](4.jpg)
点击**获取已登录账号列表**，如果无法获取则手动输入QQ号后保存即可，这样就不用每次都要登录了

## 配置NapCat
在侧边栏选择**网络配置**
![网络配置](5.jpg)
再点击**添加**选择**Websocket服务器**
![Websocket服务器](6.jpg)

按照以下内容进行配置
打开**启用**，打开**Debug**
**名称**填写一个，**Token**复制备用
![Websocket配置](7.jpg)

## 安装NapCat适配器
在Termux中新建会话
![新建会话](8.jpg)
输入**1**启动Yunzai，启动你的Yunzai

登录锅巴之后，在**插件管理**中选择**安装自定义插件**输入插件地址（从下面选一个可用的）

Gitee 源（国内网络环境推荐）
```url
https://gitee.com/qiannqq/napcat-adapter.git
```

Github 源
```url
https://github.com/qiannqq/napcat-adapter.git
```
![安装适配器](9.jpg)

安装完成后将自动重启

## 配置NapCat适配器

在**插件配置**中选择**NapCat 适配器**
把在NapCat中的Token复制到**连接Token**中并保存
![配置适配器](10.jpg)
在终端里输入
```
/重启
```

重启Yunzai

## 设置主人
在机器人的QQ中发送
```
/设置主人
```
发送在终端输出的验证码即可
![设置主人](11.png)

## 最后
每次启动时，输入**1**启动Yunzai后，再**新建会话**输入**2**启动NapCat即可使用！
