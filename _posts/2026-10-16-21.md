## 起因

事情是这样的：我前段时间买了个小相机，是 TF 卡存储，里面存了这段时间拍的一百多张的照片，然后我手一抖，全删了


当时手上只有一部手机（小米，无 root）和一个 OTG 读卡器，没有电脑
网上搜了一圈，所有教程都在说"装个 DiskDigger 吧""用 PhotoRec 扫一下吧"——问题是这些要么需要 root，要么需要电脑


所以这篇文章记录一下我是怎么在**只有手机 + Termux + 无 root** 的条件下把照片全部救回来的


> 先说结论：**SD/TF 卡没有 TRIM**，删除只是把文件系统里的目录项标记为"空闲"，照片的二进制本体还躺在扇区里
只要从现在起没人往卡里写东西，恢复概率非常高
{: .prompt-info }

## 第一条铁律：立刻停止一切写入

在动手之前，先做这几件事，它们决定了你能救回多少：

1. **不要再往卡里写任何东西** —— 别开相机、别截图、别下载文件
特别注意：**别安装任何"数据恢复 APP"**，安装过程本身就在写存储

2. 设置 → 存储 → 卸载 TF 卡（或者直接拔出来放好）

3. **绝对不要格式化，不要点"修复 SD 卡"**


## 为什么 `dd` 直接读卡是行不通的

卡挂上之后，我在 Termux 里查了一下挂载情况：

```bash
df -h | grep -iE 'media_rw|storage'
```

能看到这么两行：

```
/dev/block/vold/public:8,97   500G  3.0M  500G  /mnt/media_rw/5D44-A38F
/dev/fuse                     500G  3.0M  500G  /storage/5D44-A38F
```

这里有个关键信息：主设备号 `8` 说明这是一张**走 USB 的读卡器**，也就是块设备 `/dev/block/vold/public:8,97`


那直接 `dd` 它行不行？

```bash
dd if=/dev/block/vold/public:8,97 of=/dev/null bs=4096 count=1
# dd: failed to open '/dev/block/vold/public:8,97': Permission denied
```

不出所料
无 root 的情况下，SELinux 会挡住 `/dev/block/` 下的所有块设备节点，`dd`、`photorec`、`testdisk` 全都白搭


> **另外一个很容易误解的点**：就算你能 `cd /storage/5D44-A38F` 进去翻文件，也**看不到被删的照片**
删除只是抹掉了目录项，`ls` 根本没有入口
想救数据，必须绕过文件系统直接读扇区
{: .prompt-warning }

## 思路转变：不读块设备，直接跟读卡器"对话"

既然 Android 不让我碰块设备，那就绕开 Android 的存储栈，直接跟 USB 读卡器本身通信


这里有三个东西帮我绕过了限制：

- **`termux-usb`**：Termux:API 提供的工具，走的是 Android 官方 USB 授权通道
它会弹出授权框，用户点确认后，**返回一个已经打开的 USB 设备文件描述符（fd）**
这个过程不需要 root

- **`libusb` 的 `libusb_wrap_sys_device()`**：可以直接包装一个已有的 fd，不需要自己去扫 `/dev/bus/usb`（后者无 root 会被拒绝）

- **USB 大容量存储设备都遵循 SCSI 协议**：读卡器本质上就是个 SCSI 设备，我只要给它发一个 `READ(10)` 命令，它就会把指定 LBA 的扇区原样吐回来


数据传输用的是 **Bulk-Only Transport（BOT）** 协议，流程很简单：

```
发 CBW(31字节命令块)  →  收数据  →  收 CSW(13字节状态)
```

`CBW` 里塞一条 10 字节的 SCSI `READ(10)` 命令（操作码 `0x28`），带上起始 LBA 和要读的扇区数，读卡器就会把数据通过 bulk-in 端点送回来


这样，扇区数据我拿到了，跟文件系统没有任何关系，SELinux 也管不着

## 第一步：确认手机看到了读卡器

```bash
termux-usb -l
```

返回 `[]` 说明没识别到，回去查 OTG 和硬件；返回类似下面的路径就没问题：

```json
[
  "/dev/bus/usb/001/015"
]
```

> **设备号每次重插都可能变**，所以每次操作前都重新跑一次 `termux-usb -l`，别照抄之前的号
{: .prompt-info }

## 第二步：编译 `scsi_dump`

把 [scsi_dump.c](#scsi_dumpc) 保存到home目录，然后：

```bash
cd ~
clang -O2 -o scsi_dump scsi_dump.c -lusb-1.0
```

## 第三步：探测容量，确认链路通了

这里有个坑要单独说：**`termux-usb -e` 不会替换你命令里的 `%d`**，它是把 fd 号码**追加到你的命令参数末尾**
所以我第一次跑的时候：

```bash
termux-usb -r -e './scsi_dump %d --info' /dev/bus/usb/001/015
# fd 无效: %d
```

程序收到的第一个参数是字面量 `%d`
解决办法是加一层 wrapper，把最后一个参数（fd）挪到第一位
见 [scsi_wrap.sh](#scsi_wrapsh)


```bash
termux-usb -r -e "$HOME/scsi_wrap.sh --info" /dev/bus/usb/001/015
```

弹窗点允许
成功的话会打印：

```
[wrapper] fd=7  参数: --info
端点: IN=0x81 OUT=0x02
容量: 1048576000 扇区 x 512 字节 = 536.9 GB (500 GiB)
```

看到容量就说明链路通了，libusb 已经能发 SCSI 命令读卡


> Android 可能会提示"USB 设备已移除"，这是 libusb 接管了设备导致的，**正常现象，别慌**
{: .prompt-info }

## 第四步：用 `--probe` 判断是不是扩容卡

这一步很关键，能省掉好几个小时


扩容卡（虚标容量）超出真实容量的部分，读出来要么是错误要么是垃圾数据
扫这些区域纯属浪费时间——而且表现得很像"读卡器坏了"


```bash
termux-usb -r -e "$HOME/scsi_wrap.sh --probe 24" /dev/bus/usb/001/017
```

它会采样 24 个点并打印一张表：

```
序号 LBA          位置(GiB) 状态
0      0            0.0        有数据
...
23     1048575999   500.0      全0 (空白)

结论: 全部采样点都能读出，未发现硬错误边界

```

如果发现了读错误，它会自动二分定位真实容量边界，并告诉你"这是一张扩容卡，真实容量约 XX GiB"，同时给出可以直接用的扫描命令


> 顺便一提，我这张卡的扇区数是 `1048576000`——这个数字太整了（= 1000 × 1048576），一开始我高度怀疑是扩容卡
真实 500G 卡一般是 `976773168` 这种零碎数字
不过 probe 下来全部能读，是真卡
{: .prompt-tip }

## 第五步：读卡 + 抠图

拿到扇区数据之后，下一步是**从里面找出照片**
这个技术叫 **file carving（文件雕刻）**：不管文件系统，直接按文件头的特征字节找文件


### 为什么不用现成工具

PhotoRec 在这个环境下装不上（其实就算装上，它也读不到 USB 设备）
所以我自己写了一个 `carve_photos.py`


### JPEG 的边界怎么定

最朴素的写法是"找 `FFD8FF` 开头，找 `FFD9` 结尾"，但这有两个大问题：

1. JPEG 内部（比如 EXIF 缩略图）也会出现 `FFD9`，会导致文件被截断

2. 随机数据里的假 `FFD8FF` 后面往往没有 `FFD9`，会一路吞掉几十 MB 的错误数据


我的做法是**按 JPEG 的段结构解析**：

```
FFD8 (SOI)
  → FFE0/FFE1/... 各种段，每段前 2 字节是长度
  → FFDA (SOS) 进入熵编码数据区
  → 数据区里逐字节前进，只有 FF00(转义) / FFD0-D7(重启标记) 可以跳过
  → FFD9 (EOI) 结束
```

这样就精确多了
HEIC / MP4 / MOV 用的是 ISO-BMFF 的 box 链（4 字节长度 + 4 字节类型），同理按 box 逐个跳到文件末尾


### 一个让我速度暴跌 20 倍的 bug

第一版跑起来，前 67MB 速度是 13MB/s，然后一路跌到 0.6MB/s
查下来是这个问题：

> 遇到一个"有 JPEG 头但没有结尾标记"的碎片时，程序会一直往后攒数据，攒到 48MB 才判定放弃
一到照片密集区，每碰一个碎片就白读 48MB


修复办法很经典：**给每个文件定一个上界——它不可能越过下一个文件头**


```python
nj_rel, _ = find_next_sig(buf, rel + 3, sigs)
upto = base + nj_rel if nj_rel is not None else eff_end
r = cur["parser"].feed(buf, base, upto)
```

加上这个之后，扫描变成了线性时间
我用极端对抗数据测过（每 200KB 插一个没有结尾的假 JPEG 头）：修复前卡死，修复后 17MB 用 1.1 秒，8 张真图全部字节级还原


### 两种跑法

**管道模式**：读卡和抠图同时跑，扇区在内存里过一遍，只把照片落盘，**不需要几百 GB 的中间镜像**


```bash
termux-wake-lock
mkdir -p ~/recovered
termux-usb -r -e "$HOME/scsi_wrap.sh -n 8388608 -b 128 -o -" /dev/bus/usb/001/002 \
  | python3 ~/carve_photos.py - ~/recovered --only jpg --min-size 50000 --total 500G
```

`-n 8388608` = 只读前 4GB 试水（8388608 × 512 字节）
确认能出图了，去掉 `-n` 全卡扫


**分段模式（推荐）**：管道模式一旦中断就得从头再来
500G 全扫要好几个小时，中途 OTG 掉一下就前功尽弃
分段模式每段单独存镜像、抠完就删，**中断后重跑会自动跳过已完成的段**：

```bash
SEG_GB=10 bash ~/seg_scan.sh
```

每段 10GB 大约 14 分钟，峰值只占 10GB 临时空间


## 第六步：整理成能看的照片库

carving 出来的文件是编号的（`jpg_000001_123456.jpg`），原始文件名和目录结构**已经永久丢失**，这是这个技术的固有限制，任何工具都一样


不过 JPEG 里通常还留着 EXIF 拍摄时间，可以靠它还原：

```bash
python3 ~/rename_by_exif.py ~/recovered ~/照片_已恢复 --min-size 50000
```

会按 `20240315_142530.jpg` 命名、按年月建子目录（`2024-03/`）、md5 去重，打不开的挑到 `_broken/`，太小的缩略图挑到 `_thumbs/`

## 我踩过的坑

整理一下，省得后人重蹈覆辙：

| 坑 | 现象 | 原因 / 解法 |
|---|---|---|
| `%d` 不生效 | `fd 无效: %d` | `termux-usb -e` 不替换 `%d`，而是把 fd **追加到参数末尾**，用 wrapper 换位 |
| `~` 不展开 | `No such file or directory` | 双引号里 `~` 不会被展开，用 `$HOME` |
| 设备号变了 | `No such device` | 重插读卡器后设备号会变，每次重新 `termux-usb -l` |
| OTG 自动关闭 | 跑到一半读不出数据 | 小米 OTG 空闲 10 分钟自动关，去设置里找"永不关闭" |
| 速度暴跌 | 13MB/s → 0.6MB/s | 假文件头导致每个碎片白读 48MB，用"下一个文件头"作上界 |
| 只扫了 4MB 就停 | 进度异常终止 | 内层循环变量名 `limit` 覆盖了外层参数，改名 |
| Termux 被卡死 | 读不出数据后无限重试 | 加 `--max-errors`，连续失败就主动退出 |
| 相对路径找不到 | `./scsi_dump: No such file or directory` | `termux-usb -e` 里用绝对路径 |

## 完整脚本源码

下面是我用到的全部脚本，可以直接复制使用


### check_sd.sh

诊断脚本，用来看清卡有没有挂上、块设备能不能读、剩余空间够不够


```bash
#!/data/data/com.termux/files/usr/bin/bash
# check_sd.sh —— 诊断 TF 卡在无 root 手机上能否被原始扇区读取
# 用法：bash check_sd.sh

echo "=============== 1. 系统信息 ==============="
echo "Android 版本: $(getprop ro.build.version.release 2>/dev/null)"
echo "机型: $(getprop ro.product.model 2>/dev/null)"
echo "Termux 用户: $(id)"
echo ""

echo "=============== 2. 块设备（TF 卡候选）==============="
for d in /dev/block/mmcblk1 /dev/block/mmcblk1p1 /dev/block/mmcblk0 /dev/block/mmcblk0p1; do
    [ -e "$d" ] && ls -l "$d" 2>/dev/null
done
echo "--- /dev/block 下所有含 mmc 或 vold 的节点 ---"
ls -l /dev/block/ 2>/dev/null | grep -Ei 'mmc|vold|sd' || echo "(无法列出 /dev/block 或没有匹配项)"
echo ""

echo "=============== 3. 挂载情况 ==============="
mount 2>/dev/null | grep -Ei 'media_rw|storage|sdcard|vfat|exfat|f2fs|fuseblk' || echo "(无匹配)"
echo ""

echo "=============== 4. 关键测试：能否直接读扇区 ==============="
readable=0
for d in $(ls /dev/block/ 2>/dev/null | grep -E '^mmcblk1|^mmcblk0|^vold' | sed 's|^|/dev/block/|'); do
    if timeout 8 dd if="$d" of=/dev/null bs=4096 count=1 2>/tmp/dd_err.txt; then
        echo "  [可读] $d"
        readable=1
    else
        echo "  [不可读] $d  -> $(tr '\n' ' ' < /tmp/dd_err.txt | tail -c 120)"
    fi
done
[ "$readable" = "0" ] && echo "  >>> 结论：所有块设备都读不了，块设备路线不可行"
[ "$readable" = "1" ] && echo "  >>> 结论：至少有一个块设备可读，可以直接流式恢复！"
echo ""

echo "=============== 5. USB/读卡器 ==============="
ls -l /dev/bus/usb/ 2>/dev/null || echo "(无法访问 /dev/bus/usb)"
command -v termux-usb >/dev/null && echo "termux-usb: 已安装" || echo "termux-usb: 未安装（需 pkg install termux-api + 安装 Termux:API App）"
echo ""

echo "=============== 6. 存储空间（恢复结果要放这）=============="
df -h 2>/dev/null | grep -Ei 'Filesystem|/storage/emulated|/data|/sdcard' || df -h /data
echo ""

echo "=============== 7. 建议 ==============="
if [ "$readable" = "1" ]; then
    echo "直接跑：python3 carve_photos.py <上面的可读设备> ~/recovered --only jpg --limit 2G"
else
    echo "块设备不可读，需要走 termux-usb + OTG 路线，或找台电脑/借读卡器插电脑用 PhotoRec
"
fi
```

### scsi_wrap.sh

参数换位器
`termux-usb -e` 把 fd 追加在末尾，而 `scsi_dump` 要求 fd 是第一个参数


```bash
#!/data/data/com.termux/files/usr/bin/bash
#
# scsi_wrap.sh —— 参数换位器
#
# 为什么需要：termux-usb -e 的做法是把 USB 设备的 fd 号码"追加"到你命令的参数末尾，
#             而 scsi_dump 要求 fd 是第 1 个参数
这个脚本把最后一个参数（fd）挪到
#             最前面，其余参数原样保留

#
# 用法：
#   termux-usb -r -e "$HOME/scsi_wrap.sh --info" /dev/bus/usb/001/015
#   termux-usb -r -e "$HOME/scsi_wrap.sh -b 32 --info" /dev/bus/usb/001/015
#
# 注意：每次重插读卡器，设备号都可能变，先跑 termux-usb -l 确认


EXE="$HOME/scsi_dump"

if [ $# -lt 1 ]; then
    echo "用法: $0 [scsi_dump参数...] <fd>   （fd 由 termux-usb 自动追加）" >&2
    exit 1
fi

# 最后一个参数就是 termux-usb 传进来的 fd
FD="${!#}"

# 其余参数（去掉末尾那个 fd）
if [ $# -gt 1 ]; then
    ARGS=("${@:1:$(( $# - 1 ))}")
else
    ARGS=()
fi

echo "[wrapper] fd=$FD  参数: ${ARGS[*]}" >&2

exec "$EXE" "$FD" "${ARGS[@]}"
```

### scsi_dump.c

核心程序：通过 fd 用 libusb 给读卡器发 SCSI 命令，逐扇区把卡读出来


```c
/*
 * scsi_dump.c —— 通过 termux-usb 拿到的 fd，用 libusb 直接给 USB 读卡器发
 *                SCSI READ(10) 命令，把 TF 卡的原始扇区读出来

 *
 * 为什么需要它：无 root 时 SELinux 挡住块设备节点，dd 直接 Permission denied

 *               但 termux-usb 走的是 Android 官方 USB 授权通道，拿到的是已经打开的
 *               fd，libusb 可以直接 wrap 它，从而绕过文件系统逐扇区读卡

 *
 * 编译：
 *   pkg install clang libusb
 *   clang -O2 -o scsi_dump scsi_dump.c -lusb-1.0
 *
 * 用法：
 *   # 先看卡容量（fd 由 termux-usb -e 以 $1 传入）
 *   termux-usb -r -e './scsi_dump %FD% --info' /dev/bus/usb/001/002
 *
 *   # 整卡镜像到文件
 *   termux-usb -r -e './scsi_dump %FD% -o /sdcard/sd.img' /dev/bus/usb/001/002
 *
 *   # 只读前 4GB，输出到 stdout（可接管道，最省空间）
 *   termux-usb -r -e './scsi_dump %FD% -n 8388608 -o -' /dev/bus/usb/001/002
 *
 * 参数：
 *   fd            USB 设备文件描述符（termux-usb 传进来）
 *   -o PATH       输出路径，"-" 表示 stdout（默认 stdout）
 *   -s LBA        起始扇区，默认 0
 *   -n BLOCKS     读取扇区数，默认全部
 *   -b BLOCKS     每次 SCSI 命令读多少扇区，默认 128（64KB）
 *   --info        只打印容量信息后退出
 */

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdint.h>
#include <unistd.h>
#include <errno.h>
#include <time.h>
#include <libusb-1.0/libusb.h>

#define CBW_SIG 0x43425355  /* "USBC" little-endian */
#define CSW_SIG 0x53425355  /* "USBS" little-endian */
#define TIMEOUT 20000       /* ms，慢卡可能需要更长 */

#pragma pack(push, 1)
typedef struct {
    uint32_t sig;
    uint32_t tag;
    uint32_t len;
    uint8_t  flags;
    uint8_t  lun;
    uint8_t  cblen;
    uint8_t  cb[16];
} cbw_t;

typedef struct {
    uint32_t sig;
    uint32_t tag;
    uint32_t residue;
    uint8_t  status;
} csw_t;
#pragma pack(pop)

static libusb_device_handle *g_h = NULL;
static uint8_t g_ep_in = 0, g_ep_out = 0;
static uint32_t g_tag = 0x1234;
static int g_lun = 0;

static void die(const char *msg, int rc)
{
    fprintf(stderr, "错误: %s (libusb %d: %s)\n", msg, rc, libusb_error_name(rc));
    exit(2);
}

/* 发 CBW，需要往外传数据时额外发 data */
static int send_cbw(cbw_t *c, const uint8_t *data)
{
    int rc, transferred = 0;
    rc = libusb_bulk_transfer(g_h, g_ep_out, (uint8_t *)c, 31, &transferred, TIMEOUT);
    if (rc != 0 || transferred != 31) {
        fprintf(stderr, "CBW 发送失败 rc=%d 传了%d字节\n", rc, transferred);
        return -1;
    }
    if (c->len > 0 && data) {
        rc = libusb_bulk_transfer(g_h, g_ep_out, (uint8_t *)data, c->len, &transferred, TIMEOUT);
        if (rc != 0) return -1;
    }
    return 0;
}

/* 收数据 + 收 CSW，返回 CSW status（0=成功），-1 表示通信失败 */
static int recv_data_csw(uint8_t *buf, int want)
{
    int rc, got = 0, transferred = 0;
    csw_t csw;

    while (got < want) {
        rc = libusb_bulk_transfer(g_h, g_ep_in, buf + got, want - got, &transferred, TIMEOUT);
        if (rc != 0) {
            fprintf(stderr, "读数据失败 rc=%d (%s)，已收 %d/%d\n",
                    rc, libusb_error_name(rc), got, want);
            return -1;
        }
        if (transferred == 0) break;
        got += transferred;
    }

    transferred = 0;
    rc = libusb_bulk_transfer(g_h, g_ep_in, (uint8_t *)&csw, 13, &transferred, TIMEOUT);
    if (rc != 0) {
        fprintf(stderr, "读 CSW 失败 rc=%d\n", rc);
        return -1;
    }
    if (transferred != 13 || csw.sig != CSW_SIG || csw.tag != g_tag - 1) {
        fprintf(stderr, "CSW 校验失败 (sig=%08x tag=%u 收到%d字节)\n",
                csw.sig, csw.tag, transferred);
        return -1;
    }
    return csw.status;
}

/* SCSI READ CAPACITY(10) */
static int scsi_capacity(uint32_t *last_lba, uint32_t *block_size)
{
    cbw_t c;
    uint8_t data[8];
    memset(&c, 0, sizeof(c));
    c.sig = CBW_SIG;
    c.tag = g_tag++;
    c.len = 8;
    c.flags = 0x80;            /* data-in */
    c.lun = g_lun;
    c.cblen = 10;
    c.cb[0] = 0x25;            /* READ CAPACITY(10) */

    if (send_cbw(&c, NULL) != 0) return -1;
    if (recv_data_csw(data, 8) != 0) return -1;

    *last_lba = (uint32_t)((data[0] << 24) | (data[1] << 16) | (data[2] << 8) | data[3]);
    *block_size = (uint32_t)((data[4] << 24) | (data[5] << 16) | (data[6] << 8) | data[7]);
    return 0;
}

/* SCSI TEST UNIT READY */
static int scsi_ready(void)
{
    cbw_t c;
    memset(&c, 0, sizeof(c));
    c.sig = CBW_SIG;
    c.tag = g_tag++;
    c.len = 0;
    c.flags = 0x80;
    c.lun = g_lun;
    c.cblen = 6;
    c.cb[0] = 0x00;            /* TEST UNIT READY */

    if (send_cbw(&c, NULL) != 0) return -1;
    return recv_data_csw(NULL, 0);
}

/* SCSI READ(10)，读到的数据写进 buf */
static int scsi_read10(uint32_t lba, uint16_t blocks, uint8_t *buf)
{
    cbw_t c;
    memset(&c, 0, sizeof(c));
    c.sig = CBW_SIG;
    c.tag = g_tag++;
    c.len = (uint32_t)blocks * 512;
    c.flags = 0x80;
    c.lun = g_lun;
    c.cblen = 10;
    c.cb[0] = 0x28;            /* READ(10) */
    c.cb[2] = (uint8_t)(lba >> 24);
    c.cb[3] = (uint8_t)(lba >> 16);
    c.cb[4] = (uint8_t)(lba >> 8);
    c.cb[5] = (uint8_t)(lba);
    c.cb[7] = (uint8_t)(blocks >> 8);
    c.cb[8] = (uint8_t)(blocks);

    if (send_cbw(&c, NULL) != 0) return -1;
    return recv_data_csw(buf, (int)blocks * 512);
}

/* 探测卡的真实可读范围：扩容卡超过真实容量后，读会报错或返回全 FF / 垃圾 */
static int probe_readable(uint32_t lba, uint8_t *buf)
{
    return scsi_read10(lba, 8, buf) == 0;
}

static void probe_card(uint64_t total_blocks, int nsamples)
{
    uint8_t *buf = malloc(256 * 512);
    if (!buf) { fprintf(stderr, "内存不足\n"); return; }
    if (nsamples < 2) nsamples = 2;
    if (nsamples > 256) nsamples = 256;

    fprintf(stderr, "采样 %d 个点（每点 128KB），判断卡的真实可读范围\n", nsamples);
    fprintf(stderr, "读错误的点每个最多等 %d 秒，请耐心\n\n", TIMEOUT / 1000);

    printf("%-6s %-12s %-10s %s\n", "序号", "LBA", "位置(GiB)", "状态");

    uint64_t last_good = 0;
    int first_bad = -1;

    for (int i = 0; i < nsamples; i++) {
        uint64_t lba = (uint64_t)((double)i * (double)(total_blocks - 1)
                                  / (double)(nsamples - 1));
        uint16_t n = 256;
        if (lba + n > total_blocks) n = (uint16_t)(total_blocks - lba);
        if (n < 1) n = 1;

        int st = scsi_read10((uint32_t)lba, n, buf);
        int len = n * 512;
        const char *status;

        if (st != 0) {
            status = "!!!! 读错误";
            if (first_bad < 0) first_bad = i;
        } else {
            last_good = lba;
            int all_zero = 1, all_ff = 1;
            for (int k = 0; k < len; k++) {
                if (buf[k] != 0x00) all_zero = 0;
                if (buf[k] != 0xFF) all_ff = 0;
            }
            if (all_zero)      status = "全0 (空白)";
            else if (all_ff)   status = "全FF (可疑)";
            else {
                int has_jpg = 0;
                for (int k = 0; k + 2 < len; k++) {
                    if (buf[k] == 0xFF && buf[k+1] == 0xD8 && buf[k+2] == 0xFF) {
                        has_jpg = 1; break;
                    }
                }
                status = has_jpg ? "有数据 ★含JPEG头" : "有数据";
            }
        }
        printf("%-6d %-12llu %-10.1f %s\n", i, (unsigned long long)lba,
               (double)lba * 512.0 / 1073741824.0, status);
        fflush(stdout);
    }

    printf("\n");
    if (first_bad < 0) {
        printf("结论: 全部采样点都能读出，未发现硬错误边界
\n");
        printf("      若看到大量「全FF」，仍可能是扩容卡（超出部分返回垃圾）\n");
    } else {
        /* 在最后一个好点和第一个坏点之间二分，找真实容量边界 */
        uint64_t lo = (uint64_t)((double)(first_bad - 1) * (double)(total_blocks - 1)
                                 / (double)(nsamples - 1));
        uint64_t hi = (uint64_t)((double)first_bad * (double)(total_blocks - 1)
                                 / (double)(nsamples - 1));
        fprintf(stderr, "发现读错误，在 LBA %llu ~ %llu 之间二分定位边界...\n",
                (unsigned long long)lo, (unsigned long long)hi);
        for (int it = 0; it < 24 && hi - lo > 1; it++) {
            uint64_t mid = lo + (hi - lo) / 2;
            if (probe_readable((uint32_t)mid, buf)) lo = mid;
            else hi = mid;
        }
        double real_gib = (double)lo * 512.0 / 1073741824.0;
        double real_gb  = (double)lo * 512.0 / 1e9;
        printf("结论: 真实可读容量约 LBA %llu = %.1f GiB (%.1f GB)\n",
               (unsigned long long)lo, real_gib, real_gb);
        printf("      卡标称 %.1f GiB，只有约 %.0f%% 是真的 → 这是一张扩容卡\n",
               (double)total_blocks * 512.0 / 1073741824.0,
               real_gib / ((double)total_blocks * 512.0 / 1073741824.0) * 100.0);
        printf("      照片只可能在这条线以内，扫前面这一段就够了\n");
        printf("\n建议命令（把 TOTAL_SECTORS 换成上面的 LBA 值）:\n");
        printf("  TOTAL_SECTORS=%llu SEG_GB=10 bash ~/seg_scan.sh\n",
               (unsigned long long)lo);
    }
    free(buf);
}

/* 找一个 bulk-in 和一个 bulk-out 端点 */
static void find_endpoints(void)
{
    libusb_device *dev = libusb_get_device(g_h);
    struct libusb_config_descriptor *cfg = NULL;
    if (libusb_get_active_config_descriptor(dev, &cfg) != 0) {
        /* 兜底值，绝大多数读卡器是 0x81 / 0x02 */
        g_ep_in = 0x81;
        g_ep_out = 0x02;
        return;
    }
    for (int i = 0; i < cfg->interface->altsetting->bNumEndpoints; i++) {
        const struct libusb_endpoint_descriptor *ep = &cfg->interface->altsetting->endpoint[i];
        if ((ep->bmAttributes & 0x03) != LIBUSB_TRANSFER_TYPE_BULK) continue;
        if (ep->bEndpointAddress & 0x80) g_ep_in = ep->bEndpointAddress;
        else                             g_ep_out = ep->bEndpointAddress;
    }
    libusb_free_config_descriptor(cfg);
    if (!g_ep_in)  g_ep_in = 0x81;
    if (!g_ep_out) g_ep_out = 0x02;
}

int main(int argc, char **argv)
{
    if (argc < 2) {
        fprintf(stderr, "用法: %s <fd> [-o 输出|-] [-s 起始LBA] [-n 扇区数] "
                        "[-b 每批扇区数] [--info] [--probe N] [--max-errors N]\n", argv[0]);
        return 1;
    }

    int fd = atoi(argv[1]);
    if (fd <= 0) {
        fprintf(stderr, "fd 无效: %s\n", argv[1]);
        return 1;
    }

    const char *outpath = "-";
    uint64_t start_lba = 0, nblocks = 0;
    int batch = 128;
    int info_only = 0;
    int probe_only = 0;
    int nsamples = 24;
    int max_errors = 256;      /* 连续读失败这么多次就判定设备掉线，直接退出 */

    for (int i = 2; i < argc; i++) {
        if (!strcmp(argv[i], "-o") && i + 1 < argc)        outpath = argv[++i];
        else if (!strcmp(argv[i], "-s") && i + 1 < argc)   start_lba = strtoull(argv[++i], NULL, 0);
        else if (!strcmp(argv[i], "-n") && i + 1 < argc)   nblocks = strtoull(argv[++i], NULL, 0);
        else if (!strcmp(argv[i], "-b") && i + 1 < argc)   batch = atoi(argv[++i]);
        else if (!strcmp(argv[i], "--info"))               info_only = 1;
        else if (!strcmp(argv[i], "--max-errors") && i + 1 < argc) max_errors = atoi(argv[++i]);
        else if (!strcmp(argv[i], "--probe")) {
            probe_only = 1;
            if (i + 1 < argc && argv[i + 1][0] >= '0' && argv[i + 1][0] <= '9')
                nsamples = atoi(argv[++i]);
        }
    }
    if (batch < 1) batch = 128;
    if (batch > 65535) batch = 65535;

    /* 关键：禁止 libusb 去扫 /dev/bus/usb（无 root 会被 SELinux 拒绝），
       直接用 termux-usb 给的 fd */
    struct libusb_init_option opts[] = {
        { .option = LIBUSB_OPTION_NO_DEVICE_DISCOVERY, .value = { .ival = 1 } }
    };
    libusb_context *ctx = NULL;
    int rc = libusb_init_context(&ctx, opts, 1);
    if (rc != 0) die("libusb 初始化失败", rc);

    rc = libusb_wrap_sys_device(ctx, (intptr_t)fd, &g_h);
    if (rc != 0) die("包装 fd 失败（Termux 的 libusb 版本可能太旧）", rc);

    /* Android 侧可能还握着驱动，尝试 detach；失败不影响，接口通常已是我们的 */
    libusb_detach_kernel_driver(g_h, 0);

    rc = libusb_claim_interface(g_h, 0);
    if (rc != 0) fprintf(stderr, "警告: claim interface 失败 rc=%d，仍继续尝试\n", rc);

    find_endpoints();
    fprintf(stderr, "端点: IN=0x%02x OUT=0x%02x\n", g_ep_in, g_ep_out);

    /* 等卡就绪，读卡器刚插入时常常需要几秒 */
    int ready = -1;
    for (int i = 0; i < 30; i++) {
        ready = scsi_ready();
        if (ready == 0) break;
        usleep(500000);
    }
    if (ready != 0) fprintf(stderr, "警告: 设备未报 ready (status=%d)，继续尝试读\n", ready);

    uint32_t last_lba = 0, bs = 512;
    if (scsi_capacity(&last_lba, &bs) != 0) {
        fprintf(stderr, "读容量失败，卡可能没插好\n");
        return 3;
    }
    uint64_t total_blocks = (uint64_t)last_lba + 1;
    double gb = (double)total_blocks * bs / 1e9;
    fprintf(stderr, "容量: %llu 扇区 x %u 字节 = %.1f GB (%.0f GiB)\n",
            (unsigned long long)total_blocks, bs, gb,
            (double)total_blocks * bs / 1073741824.0);

    if (info_only) {
        printf("total_blocks=%llu block_size=%u\n", (unsigned long long)total_blocks, bs);
        return 0;
    }
    if (bs != 512 && bs != 4096) {
        fprintf(stderr, "警告: 扇区大小 %u 不常见，按 %u 处理\n", bs, bs);
    }

    if (start_lba >= total_blocks) {
        fprintf(stderr, "起始 LBA 超出范围\n");
        return 1;
    }
    if (nblocks == 0 || start_lba + nblocks > total_blocks)
        nblocks = total_blocks - start_lba;

    if (probe_only) {
        probe_card(total_blocks, nsamples);
        libusb_release_interface(g_h, 0);
        libusb_close(g_h);
        libusb_exit(ctx);
        return 0;
    }

    FILE *out = stdout;
    if (strcmp(outpath, "-") != 0) {
        out = fopen(outpath, "wb");
        if (!out) {
            fprintf(stderr, "打不开输出文件 %s: %s\n", outpath, strerror(errno));
            return 1;
        }
    }

    uint8_t *buf = malloc((size_t)batch * bs);
    if (!buf) { fprintf(stderr, "内存分配失败\n"); return 1; }

    fprintf(stderr, "开始读: LBA %llu 起，共 %llu 扇区，每批 %d\n",
            (unsigned long long)start_lba, (unsigned long long)nblocks, batch);

    uint64_t done = 0;
    time_t t0 = time(NULL);
    time_t last_report = t0;
    int consecutive_err = 0;
    int hard_fail = 0;         /* 连续硬失败计数 */
    int aborted = 0;

    while (done < nblocks) {
        uint32_t todo = (uint32_t)((nblocks - done) < (uint64_t)batch
                                   ? (nblocks - done) : (uint64_t)batch);
        uint32_t lba = (uint32_t)(start_lba + done);

        int st = scsi_read10(lba, (uint16_t)todo, buf);
        if (st != 0) {
            /* 降级重试：可能是单次传输太大 */
            if (todo > 1 && consecutive_err < 3) {
                fprintf(stderr, "  LBA %u 读取失败(status=%d)，降低批大小重试\n", lba, st);
                scsi_ready();
                if (batch > 8) batch = batch / 2;
                consecutive_err++;
                usleep(200000);
                continue;
            }
            hard_fail++;
            /* 卡掉线时每个 LBA 都会失败，若无限重试会把整个进程拖死，
               所以连续失败到上限就认定设备已断开（或已超出扩容卡真实容量） */
            if (max_errors > 0 && hard_fail >= max_errors) {
                fprintf(stderr, "\n!! 连续 %d 次读不出，判定设备已掉线或超出卡的真实容量，中止
\n",
                        hard_fail);
                fprintf(stderr, "   成功读出 %llu 扇区，中断于 LBA %llu（约 %.2f GiB 处）\n",
                        (unsigned long long)done, (unsigned long long)lba,
                        (double)lba * bs / 1073741824.0);
                aborted = 1;
                break;
            }
            if (hard_fail <= 3 || hard_fail % 50 == 0)
                fprintf(stderr, "  LBA %u 跳过（读不出，填零）连续失败 %d/%d\n",
                        lba, hard_fail, max_errors);
            memset(buf, 0, (size_t)todo * bs);
        } else {
            consecutive_err = 0;
            hard_fail = 0;
        }

        size_t w = fwrite(buf, 1, (size_t)todo * bs, out);
        if (w != (size_t)todo * bs) {
            fprintf(stderr, "写入失败（磁盘满了？）: %s\n", strerror(errno));
            break;
        }
        done += todo;

        time_t now = time(NULL);
        if (now - last_report >= 5) {
            double secs = difftime(now, t0);
            double mb = (double)done * bs / 1048576.0;
            fprintf(stderr, "  %.0f MB / %.0f MB  %.1f%%  %.1f MB/s\n",
                    mb, (double)nblocks * bs / 1048576.0,
                    (double)done / nblocks * 100.0,
                    secs > 0 ? mb / secs : 0);
            last_report = now;
            if (out != stdout) fflush(out);
        }
    }

    free(buf);
    if (out != stdout) fclose(out);
    else fflush(stdout);

    fprintf(stderr, "完成: 读出 %.1f MB，耗时 %.0f 秒\n",
            (double)done * bs / 1048576.0, difftime(time(NULL), t0));
    if (aborted)
        fprintf(stderr, "（异常中止，退出码 4；已读部分已写入，可从 LBA %llu 继续）\n",
                (unsigned long long)(start_lba + done));

    libusb_release_interface(g_h, 0);
    libusb_close(g_h);
    libusb_exit(ctx);
    return aborted ? 4 : 0;
}
```

参数说明：

| 参数 | 作用 |
|---|---|
| `-o PATH` | 输出路径，`-` 表示 stdout（可以接管道） |
| `-s LBA` | 起始扇区，默认 0 |
| `-n BLOCKS` | 读多少扇区，默认全部 |
| `-b BLOCKS` | 每次 SCSI 命令读多少扇区，默认 128（不稳定就调小） |
| `--info` | 只打印容量信息后退出 |
| `--probe N` | 采样 N 个点，判断是不是扩容卡 |
| `--max-errors N` | 连续失败 N 次判定掉线，主动退出（防卡死） |

退出码：`0` 正常完成，`4` 异常中止（已读部分仍会写入，可以从中断的 LBA 继续）


### carve_photos.py

从扇区流里抠照片
支持 JPEG / PNG / HEIC / MP4 / MOV，流式扫描、支持 stdin 管道、支持断点续扫


```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
carve_photos.py —— 从 TF 卡 / 磁盘镜像里"抠"出照片（file carving），流式扫描，不需要中间镜像

特点：
  - 边读边抠，128G 的卡不需要 128G 的镜像空间，只要放得下恢复出来的照片
  - JPEG 按段结构解析定边界（不是简单找 FFD8/FFD9），误报少、文件大小准
  - HEIC/MP4/MOV 按 box 链解析定边界
  - 支持断点续扫（Ctrl+C 或手机杀后台后，重跑同一条命令自动接着扫）
  - 支持 --limit 只扫一部分（先试水，确认能出图再全扫）
  - 纯标准库，pip 什么都不用装

用法：
    # 1) 先试水：只扫前 2GB，看看能不能出图
    python3 carve_photos.py /dev/block/mmcblk1 ~/recovered --limit 2G

    # 2) 确认有效后全扫
    python3 carve_photos.py /dev/block/mmcblk1 ~/recovered

    # 只抠 JPEG，且只要大于 100KB 的（过滤缩略图），显示进度更频繁
    python3 carve_photos.py sdcard.img ~/recovered --only jpg --min-size 100000

参数：
    source       块设备（/dev/block/mmcblk1）或镜像文件（sdcard.img）
    outdir       输出目录，绝对不能是源卡本身
    --only       类型，逗号分隔：jpg,png,heic,mp4,mov（默认 jpg,png,heic）
    --min-size   小于该字节数的丢弃（默认 8192；想要原图建议 50000~100000）
    --limit      只扫前 N 字节，支持 K/M/G/T 后缀
    --resume     断点续扫状态文件（默认 outdir/.carve_state.json）
"""

import argparse
import hashlib
import json
import os
import signal
import sys
import time

# ---------------- 文件头特征 ----------------
SIGNATURES = [
    (b"\xff\xd8\xff", "jpg"),
    (b"\x89PNG\r\n\x1a\n", "png"),
    (b"\x00\x00\x00\x18ftypheic", "heic"),
    (b"\x00\x00\x00\x18ftypheix", "heic"),
    (b"\x00\x00\x00\x18ftypmif1", "heic"),
    (b"\x00\x00\x00\x18ftypmsf1", "heic"),
    (b"\x00\x00\x00\x18ftyphevc", "heic"),
    (b"\x00\x00\x00\x18ftypisom", "mp4"),
    (b"\x00\x00\x00\x18ftypmp42", "mp4"),
    (b"\x00\x00\x00\x1cftypqt  ", "mov"),
]
PNG_END = b"IEND\xaeB`\x82"

BLOCK = 4 * 1024 * 1024        # 每次读 4MB
ALIGN = 4096                   # 块设备读取对齐
ABANDON = 48 * 1024 * 1024     # 单个文件攒到 48MB 还没结尾 → 判定坏文件，放弃
PROGRESS_EVERY = 32 * 1024 * 1024


def parse_size(s):
    s = s.strip().upper()
    units = {"K": 1024, "M": 1024**2, "G": 1024**3, "T": 1024**4}
    if s and s[-1] in units:
        return int(float(s[:-1]) * units[s[-1]])
    return int(s)


def human(n):
    for u in ("B", "KB", "MB", "GB", "TB"):
        if n < 1024 or u == "TB":
            return f"{n:.1f}{u}"
        n /= 1024


# ---------------- JPEG 增量解析 ----------------
class JpegParser:
    """从 SOI 起按段结构增量推进，返回 EOI 之后的绝对偏移；数据不够返回 None；结构坏返回 -1"""

    def __init__(self, start_abs):
        self.i = start_abs + 2        # 跳过 SOI (FFD8)
        self.in_scan = False

    def feed(self, buf, base, limit_abs):
        """推进解析，最多到 limit_abs
返回：结束绝对偏移 / None(数据不够) / -1(结构坏)"""
        end_buf = len(buf) + base     # buf 覆盖到这个绝对偏移
        top = min(limit_abs, end_buf)
        while self.i < top - 1:
            rel = self.i - base
            if rel < 0:
                return -1
            if self.in_scan:
                # 熵编码数据区：跳到下一个 0xFF
                k = buf.find(b"\xff", rel, top - base)
                if k == -1:
                    self.i = top
                    return None
                self.i = base + k
                if self.i + 1 >= top:
                    return None
                n = buf[k + 1]
                if n == 0x00 or 0xD0 <= n <= 0xD7:      # 转义 FF00 / 重启标记
                    self.i += 2
                    continue
                if n == 0xFF:                            # 填充字节
                    self.i += 1
                    continue
                if n == 0xD9:                            # EOI
                    return self.i + 2
                self.in_scan = False                     # 遇到其它标记 → 回到段解析
                rel = self.i - base
            if buf[rel] != 0xFF:
                return -1                                # 段链断了
            m = buf[rel + 1]
            if m == 0xFF:
                self.i += 1
                continue
            if m == 0xD9:
                return self.i + 2
            if m == 0x00:
                return -1
            self.i += 2
            if m == 0x01 or 0xD0 <= m <= 0xD7:
                continue
            if m == 0xDA:                                # SOS → 进入熵编码数据区
                self.in_scan = True
                continue
            if self.i + 2 > top:
                return None
            ln = int.from_bytes(buf[self.i - base:self.i - base + 2], "big")
            if ln < 2 or self.i + ln > top:
                if self.i + ln > end_buf:
                    return None                          # 段长度超出已读数据，等更多数据
                return -1
            self.i += ln
        return None


# ---------------- ISO-BMFF (HEIC/MP4/MOV) box 链解析 ----------------
class BoxParser:
    """按 box(长度+类型) 链推进到文件结束
返回结束绝对偏移 / None / -1"""

    def __init__(self, start_abs):
        self.i = start_abs
        self.start = start_abs
        self.ok = False

    @staticmethod
    def _plausible(typ):
        return all((48 <= c <= 57) or (97 <= c <= 122) or (65 <= c <= 90)
                   or c in (32, 45, 46, 95) for c in typ)

    def feed(self, buf, base, limit_abs):
        top = min(limit_abs, len(buf) + base)
        while self.i + 8 <= top:
            rel = self.i - base
            size = int.from_bytes(buf[rel:rel + 4], "big")
            typ = bytes(buf[rel + 4:rel + 8])
            hdr = 8
            if size == 1:                                # 64 位长度
                if self.i + 16 > top:
                    return None
                size = int.from_bytes(buf[rel + 8:rel + 16], "big")
                hdr = 16
            if size == 0:                                # 到文件末尾
                return top
            if size < hdr or not self._plausible(typ):
                # box 链断在文件末尾 → 前面解析到的就是完整文件
                return self.i if self.ok else -1
            if self.i + size > top:
                return None                              # 等更多数据
            self.i += size
            self.ok = True
        return None


class PngParser:
    def __init__(self, start_abs):
        self.start = start_abs

    def feed(self, buf, base, limit_abs):
        rel = self.start - base
        p = buf.find(PNG_END, max(rel + 8, 0), len(buf))
        if p != -1:
            return base + p + len(PNG_END)
        return None


def make_parser(kind, start_abs):
    if kind == "jpg":
        return JpegParser(start_abs)
    if kind == "png":
        return PngParser(start_abs)
    return BoxParser(start_abs)


def find_next_sig(buf, i, sigs):
    """在 buf 里从位置 i 起找最近的一个文件头，返回 (索引, 类型) 或 (None, None)"""
    best = None
    for sig, k in sigs:
        j = buf.find(sig, i)
        if j != -1 and (best is None or j < best[0]):
            best = (j, k)
    return best if best else (None, None)


# ---------------- 主流程 ----------------
def carve(src, outdir, only, min_size, limit, state_path, total_hint=None):
    os.makedirs(outdir, exist_ok=True)
    sigs = [s for s in SIGNATURES if s[1] in only]

    stream = (src == "-" or src == "/dev/stdin")
    if stream:
        # 管道模式：配合 scsi_dump 边读卡边抠，不需要几百 G 的中间镜像
        fd = 0
        total = None
        try:
            import fcntl
            fcntl.fcntl(fd, fcntl.F_SETFL, os.O_NONBLOCK)
            fcntl.fcntl(fd, fcntl.F_SETFL, 0)
        except Exception:
            pass
        print("源: stdin（管道流式输入）")
    else:
        fd = os.open(src, os.O_RDONLY)
        try:
            total = os.lseek(fd, 0, os.SEEK_END) if os.path.isfile(src) else None
            if total is None:
                try:
                    import fcntl
                    buf = bytearray(8)
                    fcntl.ioctl(fd, 0x80081272, buf, True)  # BLKGETSIZE64
                    total = int.from_bytes(bytes(buf), "little")
                except Exception:
                    total = None
            os.lseek(fd, 0, os.SEEK_SET)
        except Exception:
            total = None
    if total is None and total_hint:
        total = total_hint
    if limit and (total is None or limit < total):
        total = limit

    # 输出目录剩余空间检查
    st = os.statvfs(outdir)
    free = st.f_bavail * st.f_frsize
    print(f"源: {src}   大小: {human(total) if total else '未知'}")
    print(f"输出目录可用空间: {human(free)}")
    if free < 2 * 1024**3:
        print("  ! 可用空间不足 2GB，恢复大文件时可能中途写满，建议先清理")

    # 断点续扫状态
    state = {"base": 0, "kind": None, "start": 0, "count": 0}
    if stream:
        # 管道无法回退，续扫只能靠 scsi_dump 的 -s 参数从指定 LBA 重来
        print("（管道模式不支持断点续扫，如需中断请记录进度后改用什么参数重跑）")
        try:
            if os.path.exists(state_path):
                os.remove(state_path)
        except Exception:
            pass
    elif os.path.exists(state_path):
        try:
            state.update(json.load(open(state_path)))
            print(f"发现续扫状态，从第 {human(state['base'])} 处继续（已恢复 {state['count']} 个）")
        except Exception:
            print("续扫状态损坏，从头开始")

    seen = set()
    count = state["count"]

    def save(payload, kind, off):
        nonlocal count
        if len(payload) < min_size:
            return False
        h = hashlib.md5(payload).hexdigest()
        if h in seen:
            return False
        seen.add(h)
        name = f"{kind}_{count:06d}_{off}.{kind}"
        with open(os.path.join(outdir, name), "wb") as o:
            o.write(payload)
        count += 1
        return True

    base = (state["base"] // ALIGN) * ALIGN
    buf = bytearray()
    scan_abs = base
    cur = None
    if state["kind"]:
        cur = {"kind": state["kind"], "start": state["start"],
               "parser": make_parser(state["kind"], state["start"])}
        scan_abs = max(state["start"], base)

    last_report = 0
    t0 = time.time()
    eof = False
    stop = False

    def on_sigint(sig, frm):
        nonlocal stop
        stop = True
        print("\n收到中断，正在保存进度…")

    signal.signal(signal.SIGINT, on_sigint)

    pos = base
    while True:
        if stop:
            break
        if limit and pos >= limit:
            eof = True
            break
        want = BLOCK
        if limit:
            want = min(want, limit - pos)
        try:
            if stream:
                # 管道可能一次给不满，循环补齐
                parts, got = [], 0
                while got < want:
                    c = os.read(fd, want - got)
                    if not c:
                        break
                    parts.append(c)
                    got += len(c)
                chunk = b"".join(parts)
            else:
                chunk = os.pread(fd, want, pos)
        except OSError as e:
            print(f"\n读取失败 @{pos}: {e}")
            break
        if not chunk:
            eof = True
            break
        pos += len(chunk)
        buf = buf + bytearray(chunk) if buf else bytearray(chunk)

        eff_end = len(buf) + base          # buf 覆盖到的绝对偏移

        while True:
            if cur is None:
                # 找下一个文件头
                best = None
                for sig, k in sigs:
                    j = buf.find(sig, scan_abs - base)
                    if j != -1 and (best is None or j < best[0]):
                        best = (j, k, len(sig))
                if best is None:
                    scan_abs = eff_end
                    break
                j, k, slen = best
                st_abs = base + j
                cur = {"kind": k, "start": st_abs, "parser": make_parser(k, st_abs)}
                continue

            # 关键：给当前文件定一个上界——它不可能越过下一个文件头

            # 少了这一步，遇到一个没有结尾标记的假文件头就会一直攒到 ABANDON(48MB)，
            # 每遇到一次就白读 48MB，扫描速度会断崖式下跌

            rel = cur["start"] - base
            nj_rel, _ = find_next_sig(buf, rel + 3, sigs)
            upto = base + nj_rel if nj_rel is not None else eff_end

            r = cur["parser"].feed(buf, base, upto)
            if r is None:                                   # 到上界还没收尾
                if nj_rel is not None:
                    # 下一个文件头抢先出现 → 当前这个已损坏，跳到下一个头
                    scan_abs = base + nj_rel
                    cur = None
                    continue
                if eff_end - cur["start"] > ABANDON:        # 真的过大，放弃
                    scan_abs = cur["start"] + 3
                    cur = None
                    continue
                break                                       # 数据不够，等下一块
            if r == -1:                                     # 结构坏
                scan_abs = base + nj_rel if nj_rel is not None else cur["start"] + 3
                cur = None
                continue
            # 成功收尾
            rel = cur["start"] - base
            save(bytes(buf[rel:r - base]), cur["kind"], cur["start"])
            scan_abs = r
            cur = None
            continue

        # 裁剪缓冲区，防止内存无限增长
        if cur is None:
            keep = scan_abs - base
            if keep > 0:
                buf = bytearray(buf[keep:])
                base += keep
            else:
                buf = bytearray()
        else:
            keep = cur["start"] - base
            if keep > 0:
                buf = bytearray(buf[keep:])
                base += keep
        scan_abs = max(scan_abs, base)

        # 进度 + 定期存状态
        if pos - last_report >= PROGRESS_EVERY or eof:
            last_report = pos
            done = min(pos, total) if total else pos
            pct = f"{done / total * 100:.1f}%" if total else "?"
            spd = pos / max(time.time() - t0, 1) / 1024**2
            print(f"  {human(done)}/{human(total) if total else '?'} ({pct})  "
                  f"已恢复 {count} 个  {spd:.1f}MB/s", flush=True)
            json.dump({"base": base, "kind": cur["kind"] if cur else None,
                       "start": cur["start"] if cur else 0, "count": count},
                      open(state_path, "w"))

    json.dump({"base": base, "kind": cur["kind"] if cur else None,
               "start": cur["start"] if cur else 0, "count": count},
              open(state_path, "w"))
    if not stream:
        os.close(fd)
    print(f"\n结束：本次扫到 {human(pos)}，累计恢复 {count} 个 -> {outdir}")
    print(f"耗时 {(time.time() - t0) / 60:.1f} 分钟")
    if not eof and not stop and not stream:
        print("（未扫完，重跑同一条命令会接着扫）")
    if not stream:
        print("提示：确认照片没问题后，可删除 " + state_path)


def main():
    ap = argparse.ArgumentParser(description="流式 file carving，从 TF 卡或镜像恢复照片")
    ap.add_argument("source", help="块设备 /dev/block/mmcblk1、镜像 sdcard.img，或 - 表示 stdin 管道")
    ap.add_argument("outdir", help="输出目录（绝不能是源卡本身）")
    ap.add_argument("--only", default="jpg,png,heic", help="类型，默认 jpg,png,heic")
    ap.add_argument("--min-size", type=int, default=8192, help="最小字节数，默认 8192")
    ap.add_argument("--limit", default=None, help="只扫前 N，如 2G")
    ap.add_argument("--total", default=None, help="源总大小（仅用于显示进度百分比），如 500G")
    ap.add_argument("--state", default=None, help="续扫状态文件路径")
    args = ap.parse_args()

    only = set(x.strip() for x in args.only.split(",") if x.strip())
    outdir = os.path.expanduser(args.outdir)
    state_path = args.state or os.path.join(outdir, ".carve_state.json")
    limit = parse_size(args.limit) if args.limit else None

    if args.source not in ("-", "/dev/stdin") and not os.path.exists(args.source):
        sys.exit(f"源不存在：{args.source}")

    total_hint = parse_size(args.total) if args.total else None
    carve(args.source, outdir, only, args.min_size, limit, state_path, total_hint)


if __name__ == "__main__":
    main()
```

### seg_scan.sh

分段扫描驱动：一段一段「读卡 → 存临时镜像 → 抠图 → 删镜像」，中断可续


```bash
#!/data/data/com.termux/files/usr/bin/bash
#
# seg_scan.sh —— 分段扫描：一段一段「读卡 → 存临时镜像 → 抠图 → 删镜像」
#
# 为什么要用它：
#   管道模式一旦中断（OTG 掉线、息屏、读卡器松脱）就得从头再来
分段模式每段
#   单独落一个临时镜像，抠完立刻删，中断后重跑本脚本会自动跳过已完成的段

#
# 用法（在普通 shell 里跑，不用套 termux-usb）：
#   chmod +x seg_scan.sh
#   ./seg_scan.sh
#
# 可用环境变量：
#   DEVICE=/dev/bus/usb/001/002  USB 设备路径
留空则自动探测（推荐留空，
#                                因为每次重插读卡器设备号都会变）
#   TOTAL_SECTORS=1048576000     卡总扇区数
强烈建议先用 scsi_dump --probe
#                                测出真实容量再填，能省掉扫无用区域的时间
#   SEG_GB=10                    每段多少 GB，默认 10
#   OUTDIR=$HOME/recovered       最终照片输出目录
#   TMPDIR=$HOME/segtmp          临时镜像目录（每段抠完自动删）
#   ONLY=jpg,png,heic            抠哪些类型
#   MINSIZE=50000                小于多少字节丢弃（过滤缩略图）
#   START_SEG=-1                 从第几段开始，-1 表示自动跳过已完成的
#   MAXERR=256                   连续读失败多少次判定掉线（见 scsi_dump）
#
# 注意：本脚本会反复调用 termux-usb，每次弹权限确认，勾选"记住"即可

#

HOME_DIR="$HOME"
OUTDIR="${OUTDIR:-$HOME_DIR/recovered}"
TMPDIR="${TMPDIR:-$HOME_DIR/segtmp}"
SEG_GB="${SEG_GB:-10}"
ONLY="${ONLY:-jpg,png,heic}"
MINSIZE="${MINSIZE:-50000}"
START_SEG="${START_SEG:--1}"
MAXERR="${MAXERR:-256}"
DEVICE="${DEVICE:-}"
TOTAL_SECTORS="${TOTAL_SECTORS:-1048576000}"

DONEFILE="$TMPDIR/done.txt"
mkdir -p "$OUTDIR" "$TMPDIR"
[ -f "$DONEFILE" ] || touch "$DONEFILE"

# 从 termux-usb -l 的 JSON 输出里抽出第一个设备路径
pick_device() {
    termux-usb -l 2>/dev/null \
        | grep -o '/dev/bus/usb/[0-9]*/[0-9]*' \
        | head -1
}

SECTORS_PER_GB=$(( 1024 * 1024 * 1024 / 512 ))   # 2097152
SEG_SECTORS=$(( SEG_GB * SECTORS_PER_GB ))
TOTAL_SEGS=$(( (TOTAL_SECTORS + SEG_SECTORS - 1) / SEG_SECTORS ))

echo "卡总容量: $TOTAL_SECTORS 扇区 ($(( TOTAL_SECTORS / SECTORS_PER_GB )) GB)"
echo "每段: ${SEG_GB}GB  共 $TOTAL_SEGS 段"
echo "输出: $OUTDIR   临时镜像: $TMPDIR"
echo "----------------------------------------"

if [ "$START_SEG" = "-1" ]; then
    START_SEG=0
    while grep -qx "$START_SEG" "$DONEFILE"; do
        START_SEG=$(( START_SEG + 1 ))
    done
    [ "$START_SEG" -gt 0 ] && echo "从第 $START_SEG 段继续（前面的已完成）"
fi

for (( i = START_SEG; i < TOTAL_SEGS; i++ )); do
    if grep -qx "$i" "$DONEFILE"; then
        continue
    fi

    START_LBA=$(( i * SEG_SECTORS ))
    REMAIN=$(( TOTAL_SECTORS - START_LBA ))
    [ "$REMAIN" -le 0 ] && break
    N=$SEG_SECTORS
    [ "$REMAIN" -lt "$N" ] && N=$REMAIN

    SEGIMG="$TMPDIR/seg_$(printf '%03d' "$i").img"
    echo ""
    echo "===== 第 $i / $((TOTAL_SEGS - 1)) 段  LBA $START_LBA + $N ($(( N / SECTORS_PER_GB ))GB) ====="
    echo "开始: $(date '+%H:%M:%S')"

    ok=0
    for attempt in 1 2; do
        # 设备号可能因为重插/OTG 重连而变，每次都重新探测
        if [ -z "$DEVICE" ] || [ ! -e "$DEVICE" ]; then
            DEV="$(pick_device)"
            if [ -z "$DEV" ]; then
                echo "  !! 没探测到 USB 设备
读卡器掉了？重新插一下再回车继续"
                read -r
                DEV="$(pick_device)"
                [ -z "$DEV" ] && { echo "  !! 仍未探测到，跳过本段"; continue; }
            fi
            echo "  使用设备: $DEV"
        else
            DEV="$DEVICE"
        fi

        rm -f "$SEGIMG"
        termux-usb -r -e "$HOME_DIR/scsi_wrap.sh -s $START_LBA -n $N -b 128 --max-errors $MAXERR -o $SEGIMG" "$DEV"
        rc=$?

        if [ $rc -eq 0 ] && [ -s "$SEGIMG" ]; then
            ok=1
            break
        fi

        echo "  !! 第 $i 段第 $attempt 次失败（退出码 $rc）"
        if [ $rc -eq 4 ]; then
            echo "     读卡器中途掉线或超出真实容量
请重新插卡后回车重试"
        else
            echo "     设备可能已断开，请检查后回车重试"
        fi
        rm -f "$SEGIMG"
        read -r
    done

    if [ "$ok" != "1" ]; then
        echo "  !! 第 $i 段放弃，继续下一段"
        continue
    fi

    echo "抠图中... $(date '+%H:%M:%S')"
    python3 "$HOME_DIR/carve_photos.py" "$SEGIMG" "$OUTDIR" \
        --only "$ONLY" --min-size "$MINSIZE" --state "$TMPDIR/state_$i.json"

    rm -f "$SEGIMG"
    echo "$i" >> "$DONEFILE"
    echo "第 $i 段完成 $(date '+%H:%M:%S')  已恢复: $(ls "$OUTDIR" 2>/dev/null | wc -l) 个"
done

echo ""
echo "======================================"
echo "结束
共恢复 $(ls "$OUTDIR" 2>/dev/null | wc -l) 个文件 -> $OUTDIR"
echo "整理照片："
echo "  python3 $HOME_DIR/rename_by_exif.py $OUTDIR ${OUTDIR}_已整理 --min-size 50000"
```

### rename_by_exif.py

按 EXIF 拍摄时间整理恢复出来的照片


```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
rename_by_exif.py —— 把 carve 出来的一堆编号文件整理成人能看的照片库

做四件事：
  1. 按 EXIF 里的拍摄时间重命名成 20240315_142530.jpg
  2. 按年月建子目录（2024-03/），方便按时间找回
  3. md5 去重（carving 经常抠出重复片段和缩略图）
  4. 把打不开/不完整的挑到 _broken/，把小于指定大小的缩略图挑到 _thumbs/

用法：
    python3 rename_by_exif.py ~/recovered ~/照片_已恢复
    python3 rename_by_exif.py ~/recovered ~/照片_已恢复 --min-size 50000 --no-subdir

纯标准库，不用装 Pillow
只处理 jpg（png/heic 没有 EXIF 时间就按文件顺序命名）

"""

import argparse
import hashlib
import os
import shutil
import struct
import sys
from collections import Counter

EXIF_IFD = 0x8769
TAG_DT_ORIG = 0x9003      # DateTimeOriginal
TAG_DT = 0x0132           # DateTime


def read_exif_datetime(data):
    """从 JPEG 二进制里读拍摄时间，返回 'YYYY:MM:DD HH:MM:SS' 或 None"""
    if data[:2] != b"\xff\xd8":
        return None
    i = 2
    n = len(data)
    while i < n - 3:
        if data[i] != 0xFF:
            return None
        m = data[i + 1]
        if m == 0xD9 or m == 0xDA:
            return None                                  # EXIF 只在文件头部
        i += 2
        if m in (0x01,) or 0xD0 <= m <= 0xD7:
            continue
        ln = int.from_bytes(data[i:i + 2], "big")
        if ln < 2 or i + ln > n:
            return None
        if m == 0xE1 and data[i + 2:i + 8] == b"Exif\x00\x00":
            tiff = data[i + 8:i + ln]
            return _parse_tiff(tiff)
        i += ln
    return None


def _parse_tiff(tiff):
    if len(tiff) < 8:
        return None
    bo = tiff[:2]
    if bo == b"II":
        e = "little"
    elif bo == b"MM":
        e = "big"
    else:
        return None
    try:
        if int.from_bytes(tiff[2:4], e) != 42:
            return None
        off = int.from_bytes(tiff[4:8], e)
        found = {}

        def walk(ifd_off, depth=0):
            if depth > 2 or ifd_off + 2 > len(tiff):
                return
            cnt = int.from_bytes(tiff[ifd_off:ifd_off + 2], e)
            for k in range(cnt):
                p = ifd_off + 2 + k * 12
                if p + 12 > len(tiff):
                    return
                tag = int.from_bytes(tiff[p:p + 2], e)
                typ = int.from_bytes(tiff[p + 2:p + 4], e)
                cnt2 = int.from_bytes(tiff[p + 4:p + 8], e)
                sz = {1: 1, 2: 1, 3: 2, 4: 4, 5: 8}.get(typ, 1) * cnt2
                if sz <= 4:
                    val = tiff[p + 8:p + 8 + sz]
                else:
                    vo = int.from_bytes(tiff[p + 8:p + 12], e)
                    if vo + sz > len(tiff):
                        continue
                    val = tiff[vo:vo + sz]
                if tag in (TAG_DT_ORIG, TAG_DT) and tag not in found:
                    s = val.split(b"\x00")[0].decode("ascii", "ignore").strip()
                    if len(s) >= 19:
                        found[tag] = s
                if tag == EXIF_IFD and len(val) >= 2:
                    walk(int.from_bytes(val[:2], e), depth + 1)

        walk(off)
    except Exception:
        return None
    return found.get(TAG_DT_ORIG) or found.get(TAG_DT)


def valid_jpeg(path):
    """能否被正常解码：SOI 开头、EOI 结尾、段链不断"""
    try:
        with open(path, "rb") as f:
            head = f.read(4)
            if head[:2] != b"\xff\xd8":
                return False
            f.seek(0, 2)
            size = f.tell()
            if size < 1024:
                return False
            f.seek(-2, 2)
            return f.read(2) == b"\xff\xd9"
    except Exception:
        return False


def valid_png(path):
    try:
        with open(path, "rb") as f:
            if f.read(8) != b"\x89PNG\r\n\x1a\n":
                return False
            f.seek(-8, 2)
            return f.read(8) == b"IEND\xaeB`\x82"
    except Exception:
        return False


def md5(path):
    h = hashlib.md5()
    with open(path, "rb") as f:
        for c in iter(lambda: f.read(1 << 20), b""):
            h.update(c)
    return h.hexdigest()


def main():
    ap = argparse.ArgumentParser(description="按 EXIF 时间整理恢复出来的照片")
    ap.add_argument("srcdir", help="carve 输出目录")
    ap.add_argument("dstdir", help="整理后的目录")
    ap.add_argument("--min-size", type=int, default=20000,
                    help="小于此字节数视为缩略图，默认 20000")
    ap.add_argument("--no-subdir", action="store_true", help="不建年月子目录")
    ap.add_argument("--copy", action="store_true", help="复制而非移动（更安全）")
    args = ap.parse_args()

    src = os.path.expanduser(args.srcdir)
    dst = os.path.expanduser(args.dstdir)
    for d in (dst, os.path.join(dst, "_broken"), os.path.join(dst, "_thumbs")):
        os.makedirs(d, exist_ok=True)

    files = sorted(f for f in os.listdir(src)
                   if f.lower().endswith((".jpg", ".jpeg", ".png", ".heic")))
    if not files:
        sys.exit(f"{src} 里没有图片文件")

    seen = set()
    stat = Counter()
    used = Counter()

    for i, fn in enumerate(files):
        p = os.path.join(src, fn)
        size = os.path.getsize(p)
        h = md5(p)
        if h in seen:
            stat["重复丢弃"] += 1
            continue
        seen.add(h)

        ext = os.path.splitext(fn)[1].lower()
        if size < args.min_size:
            shutil.move(p, os.path.join(dst, "_thumbs", fn))
            stat["缩略图"] += 1
            continue
        ok = valid_jpeg(p) if ext in (".jpg", ".jpeg") else (
            valid_png(p) if ext == ".png" else True)
        if not ok:
            shutil.move(p, os.path.join(dst, "_broken", fn))
            stat["损坏"] += 1
            continue

        dt = None
        if ext in (".jpg", ".jpeg"):
            with open(p, "rb") as f:
                dt = read_exif_datetime(f.read(256 * 1024))

        if dt and len(dt) >= 19:
            d, t = dt[:10].replace(":", ""), dt[11:19].replace(":", "")
            sub = f"{d[:4]}-{d[4:6]}"
            stem = f"{d}_{t}"
        else:
            sub, stem = "无时间", f"noexif_{i:05d}"

        target_dir = dst if args.no_subdir else os.path.join(dst, sub)
        os.makedirs(target_dir, exist_ok=True)
        used[stem] += 1
        name = stem if used[stem] == 1 else f"{stem}_{used[stem]}"
        target = os.path.join(target_dir, name + ext)
        k = 1
        while os.path.exists(target):
            target = os.path.join(target_dir, f"{name}_{k}{ext}")
            k += 1

        (shutil.copy2 if args.copy else shutil.move)(p, target)
        stat["已整理"] += 1
        if stat["已整理"] % 200 == 0:
            print(f"  已整理 {stat['已整理']}/{len(files)}", flush=True)

    print("\n===== 整理完成 =====")
    for k, v in stat.items():
        print(f"  {k}: {v}")
    print(f"输出目录：{dst}")
    print("  _broken/ = 不完整打不开的，_thumbs/ = 太小的缩略图")


if __name__ == "__main__":
    main()
```
