## 我们如何定义"喜欢"？

当被问及"你喜欢什么样的人"时，答案要远比"男"或"女"复杂得多

**性取向**（sexual orientation）是指个体在情感、浪漫或性方面对特定性别产生持久吸引的能力
它不是一种选择，也不应被视为异常


现代社会已经逐渐超越了"异性恋 vs 同性恋"的二元框架，认识到人类吸引模式的丰富光谱
从泛性恋到半性恋，从双灵文化到 AI 性恋者，身份标签日益精细化，反映出人们对自我认知的不断深化


这篇文章系统梳理了性取向的主要类型与发展脉络，涵盖主流分类、无性向谱系、浪漫取向的独立性、跨文化历史实践以及数字时代的新兴认同，希望能帮你更全面理解人类情感与欲望的多样性

## 一、主流与扩展性取向：从"三大类"到多元光谱

### 经典三元分类

长期以来，性取向被简化为三种基本类型：

| 类型 | 定义 |
|------|------|
| **异性恋**（heterosexual） | 主要对异性产生吸引 |
| **同性恋**（homosexual） | 主要对同性别个体产生吸引，可分为男同性恋（gay）和女同性恋（lesbian） |
| **双性恋**（bisexual） | 对两种及以上性别可能产生吸引 |

这三类构成了公众认知的基础，但现实中很多人的吸引体验远比这复杂
比如，并非所有双性恋者对男女的吸引程度均等，也有人明确排除某一性别


> **重要提示**：
>这些分类只是描述工具
>不是限制性标签
>每个人的经历都是独特的！


### 扩展性取向类型

随着社会包容度提升，更多细分身份进入了公众视野：

- **泛性恋**（pansexual）：强调"被人格而非性别吸引"，对所有性别认同者开放可能性，常自称为"性别盲"

- **全性恋**（omnisexual）：能被所有性别吸引，但承认并关注性别差异的存在

- **多性恋**（polysexual）：对多个但非全部性别产生吸引

- **酷儿**（queer）：作为流动身份的统称，拒绝固定标签

| 类型 | 是否受性别影响 | 对性别差异的关注 |
|------|:------------:|:--------------:|
| 泛性恋 | 否（性别盲） | 不强调 |
| 全性恋 | 是 | 明确承认 |
| 多性恋 | 是 | 有偏好 |

## 二、无性向谱系："没有性吸引"也是一种正常

### 什么是无性恋？

**无性恋**（asexuality）：
指个体对任何性别的人都不会产生持续性的性吸引

这是一种**正常的性取向**，不是疾病、创伤或"还没开窍"


常见误解：
- ❌ "只是缺乏经验"
- ❌ "心理有问题"
- ✅ 实为内在稳定的吸引模式

许多无性恋者仍可建立深厚的情感联结、享受亲密关系，甚至拥有浪漫伴侣——他们只是不以性吸引作为关系起点


### 无性向光谱模型

无性向并非非黑即白，而是一个连续光谱：

| 身份 | 核心特征 |
|------|---------|
| **Asexual**（无性恋） | 几乎不感受性吸引 |
| **Graysexual**（灰色无性恋） | 偶尔、微弱地体验性吸引，处于过渡地带 |
| **Demisexual**（半性恋） | 仅在建立深厚情感连接后才可能产生性吸引 |
| **Fraysexual**（陌生无性恋） | 只对陌生人有性吸引，熟悉后消失 |
| **Lithosexual**（单向性恋） | 只对不回应自己的人产生吸引 |
| **Reciprosexual**（双向性恋） | 只有对方也喜欢自己时才有性吸引 |

这些身份共同构成"无性恋光谱"（Ace Spectrum），体现了吸引模式的多样性

## 三、浪漫吸引的独立表达：爱与性可以分离

### 分裂吸引模型（Split Attraction Model）

现代性别研究提出了一个重要理论：**性吸引 ≠ 浪漫吸引**
这一"分裂吸引模型"（Split Attraction Model, SAM）已被广泛接受


研究表明，大脑中负责"性"与"爱"的神经通路不同：前者与杏仁核相关，后者涉及前额叶皮层的情感规划功能


日常生活中可见这种分离：
- "我爱上一个人，但不想和他发生关系"
- "我和 TA 做爱，但并不想谈恋爱"

一个人完全可以同时是"无性恋"却"异性浪漫"，或是"同性恋"却"无浪漫倾向"




### 浪漫取向分类

浪漫取向描述的是个体倾向于与何种性别建立恋爱关系的情感冲动：

| 浪漫取向 | 对应含义 |
|---------|---------|
| Heteroromantic | 异性浪漫 |
| Homoromantic | 同性浪漫 |
| Biromantic | 双性浪漫 |
| Panromantic | 泛性浪漫 |
| **Demiromantic**（半浪漫） | 需深厚情感基础才产生浪漫吸引 |
| **Greyromantic**（灰浪漫） | 偶尔或模糊地感受到浪漫吸引 |
| **Lithromantic**（单恋倾向） | 希望感情不被回应，否则情感消退 |
| **Cupioromantic**（渴求型无浪漫） | 虽无浪漫吸引，但仍渴望恋爱关系 |

## 四、跨文化与历史上的性取向：全球视野下的性别多样性

### 北美原住民："双灵"（Two-Spirit）

"双灵"是至少 150 个北美原住民部落共有的社会角色，指兼具男女特质的精神中介者
他们在仪式中担任祭司、歌者，被视为宇宙平衡的象征


该术语于 1990 年由原住民活动家创造，旨在恢复殖民前的文化传统


### 南亚："海吉拉"（Hijra）

在印度、巴基斯坦和孟加拉国，"海吉拉"是一个历史悠久的第三性别群体
他们多为跨性别女性或阉人，在婚礼、出生典礼中被认为能带来祝福


2014 年，印度最高法院正式承认"第三性别"的法律地位


### 萨摩亚："法阿法菲娜"（Fa'afafine）

"法阿法菲娜"意为"像女人一样生活的男性"，在萨摩亚文化中承担照顾长者、传承舞蹈与教育青少年性知识的社会职责
他们通常不寻求医学过渡，也不完全对应西方的"跨性别"概念


### 中东与东亚案例

| 文化 | 实践 |
|------|------|
| **阿曼 Xanith** | 基于性行为角色划分的三元性别观——主动方为"男性"，被动方为"xanith" |
| **中国古代"契兄契弟"** | 士子间发展出的少年同性关系，用以排遣寂寞 |
| **"磨镜"** | 宫廷女性间的相互抚慰行为，因身体相似如镜相对而得名 |

这些历史实践表明，非主流性取向并非现代发明，而是长期存在于人类社会之中

## 五、数字时代的新兴取向认同

### 新兴术语的兴起背景

社交媒体促进了小众社群的聚集与话语建构，年轻一代更注重自我描述的精确性
平台算法推荐机制加速了新术语的传播，使原本模糊的感受得以命名和共享


### 典型新兴认同

| 身份 | 定义 |
|------|------|
| **AI 性恋者** | 愿意在亲密关系中尝试使用人工智能的人群，尤其在 Z 世代中比例较高 |
| **智性恋**（sapiosexual） | 被高智商、思维敏捷者强烈吸引，甚至因此唤起性欲 |
| **兽迷**（furry fandom） | 对拟人化动物形象产生情感投入，通过创作"兽设"、穿戴兽装参与社群活动 |
| **自性恋**（autosexual） | 主要对自己产生性吸引，常表现为强烈的自恋倾向或自我性幻想 |

### 数字空间的影响

互联网降低了身份探索的门槛，青少年可在早期阶段进行自我认同实验
然而，算法回声室效应也可能加剧圈层分化，导致不同群体间理解鸿沟加深

## 最后的话：理解差异，拥抱多元

性取向不是非此即彼的选择题，而是一幅由生物、心理、文化共同绘制的流动光谱
从经典的异性恋/同性恋，到无性恋光谱、分裂吸引模型，再到跨文化的第三性别与数字时代的 AI 性恋者，人类对"喜欢"的理解正变得越来越精细


**尊重每个人的自我定义权**，是构建包容社会的第一步
请用对方愿意的方式称呼他们，倾听而不评判，陪伴而不强求
