一直想在手机上玩 Java 版 MC，试了一圈启动器，最后留在手机里的就是 [Fold Craft Launcher](https://github.com/FCL-Team/FoldCraftLauncher)（简称 FCL）。

它的自我介绍挺有意思的，直接抄过来当开场白：

> 你说得对，但是「Fold Craft Launcher」是由 FCL-Team 基于 HMCL 的核心功能，使用 PojavLauncher 后端开发的 Minecraft Java 版启动器。启动器运行在一个被称作「安卓」的系统，在这里，被系统选中的人将被授予「JVM」，导引 Java 之力。你将扮演一位名为「小白」的神秘用户，在自由的使用中安装不同版本、各有千秋独特的模组，和它们一起运行，找出崩溃闪退的原因，同时逐步发掘「xxException:」的真相。

## 它是怎么来的

FCL 不是从零写的，而是把两个成熟项目拼在了一起：

- **HMCL**（Hello Minecraft! Launcher）：提供核心逻辑，仓库里的 `fclcore` 就是移植自 `org.jackhuang.hmcl`。用 PC 版 HMCL 的朋友应该会很熟悉它的界面逻辑
- **Amethyst-Android**：PojavLauncher 的 Android fork，负责 JVM 启动和渲染后端

简单说就是：**PC 上最好用的 MC 启动器 + 手机上最成熟的 Java 版运行方案**。这组合基本是目前安卓端玩 Java 版的最优解了。

## 为什么推荐它

### 全版本通吃

从最早的 Alpha、远古版，到正式版、快照版甚至愚人节版本，都能下能跑。不用再纠结「我这个版本手机上支不支持」。

### 模组加载器几乎全覆盖

| 加载器 | 说明 |
| :--- | :--- |
| Forge / NeoForge | 传统模组生态，NeoForge 是高版本的现代分支 |
| Fabric / Quilt | 轻量现代方案，手机上跑起来更省资源 |
| OptiFine | 光影与性能优化 |
| LiteLoader | 老牌轻量客户端模组 |
| Cleanroom | Forge 的兼容层方案 |

也就是说，**电脑上玩的整合包，大部分可以直接搬到手机里跑**。

### 不用自己折腾 Java

安卓本身没有 Java 运行时的概念，普通用户根本不知道该去哪下 JRE。FCL 内置了 **Java 8 / 17 / 21 / 25** 多套运行时，首次启动点一下「安装 / 更新」就自动搞定，也支持导入自己的 Java。

高版本（1.18+）建议选 Java 17 及以上，老版本（1.16 及更早）用 Java 8，这个启动器一般会自动匹配。

### 触屏操作也能玩

手机没鼠标没键盘，这本来是玩 Java 版最大的障碍。FCL 自带：

- **虚拟鼠标**：模拟指针，拖拽视角、点背包都靠它
- **自定义按键映射**：WASD、跳跃、潜行这些键位可以自己摆，怎么顺手怎么来，还能按版本保存多套布局

### 光影也能开

配合 **VirGL / Zink / MobileGlues（MG）** 这类渲染器可以跑光影包。FCL 支持渲染器插件化，切换很方便。

按社区经验，1.18 以上版本一般用 MG 渲染器兼容性更好，老版本可以试试 VirGL。机子性能够的话，画面效果不比电脑差太多。

### 资源管理一站式

模组、整合包、材质包、光影、存档都在一个地方管，`.mrpack` / `.zip` 整合包可以直接导入。还有深色 / 浅色主题和自定义背景，颜值这块也没落下。

## 怎么装

1. 去 [Releases 页面](https://github.com/FCL-Team/FoldCraftLauncher/releases) 下载最新 APK
   - 绝大多数手机选 **arm64-v8a** 版本就够了
   - 装不上再试 **all** 全架构通用版（体积大一些）
2. 安装后打开，授予存储权限、同意协议
3. 点「安装 / 更新」把 Java 运行时装上（这一步要下几百 MB，建议连 WiFi）
4. 建账户：有正版就登微软账户，测试的话选「离线账户」，起个纯英文数字的用户名就行
5. 左侧「下载」里挑版本，需要模组就顺手勾上加载器，等它下完就能启动

![游戏内截图](2.jpg)

内存分配这块，社区普遍的建议是：别低于 3GB，中高端机给 4–6GB 比较稳妥，别一次性全拉满，要给系统留点余量。具体还是看你手机多大运存，多试几次。

## 几个提醒

- **性能预期要放平**。 Java 版在手机上是靠转译 + 软件渲染跑的，中低端机开高版本整合包大概率会卡，这是物理限制，不是启动器的问题
- **闪退先查三样**：渲染器对不对、内存够不够、Java 版本匹不匹配。版本旁边的「版本独立设置」里可以单独改
- **离线账户进不了正版服务器**，想联机得另想办法
- **整合包路径尽量全英文**，中文路径是这类启动器翻车的经典原因
