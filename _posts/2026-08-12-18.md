## 1. 概述

Aiyu 模块插件是一种扩展应用能力的机制，允许开发者通过 **前端 HTML 页面** 与 **后端 QuickJS 脚本** 的组合，为应用添加悬浮窗、Token 统计、游戏化养成、自定义指令响应等功能。

模块采用声明式配置（`manifest.json`）+ 前后端代码分离的架构：
- **前端**：负责可视化配置面板、数据展示、用户交互。
- **后端**：负责接收 Native 事件、处理业务逻辑、读写持久化数据。
- **Native 层**：提供桥接 API，供前后端调用以读写配置、显示悬浮窗、下载文件等。

## 2. 模块类型与引擎模式

### 2.1 模块类型（`type`）

| 类型值 | 说明 |
|--------|------|
| `TOOL` | 工具型模块，提供辅助功能（如统计、悬浮窗、动画等）。 |

### 2.2 引擎模式（`engine`）

| 引擎值 | 说明 | 典型场景 |
|--------|------|----------|
| `hybrid` | 同时包含前端配置页（`entry`）与后端脚本（`js_entry`）。前端通过 `window.AiyuNative.call()` 与 Native 通信；后端通过全局函数暴露事件处理器。 | Token 查看器、AI 宠物养成 |
| `quickjs` | 仅包含后端脚本（`js_entry`），无独立配置页面。逻辑完全在 QuickJS 沙箱中运行。 | 图片下载器 |

> **注意**：纯前端模块（无 `js_entry`）可省略 `engine` 字段，此时仅作为静态页面展示。

## 3. 模块清单（Manifest）规范

每个模块根目录必须包含 `manifest.json`，完整字段如下：

```json
{
  "id": "module_unique_id",
  "name": "模块显示名称",
  "version": "1.0.0",
  "author": "作者名",
  "description": "模块功能描述",
  "type": "TOOL",
  "engine": "hybrid",
  "entry": "index.html",
  "js_entry": "main.js",
  "permissions": [
    "display_floating_window"
  ],
  "permissions_on_install": [
    "display_floating_window"
  ],
  "floating_window": {
    "supported": true,
    "default_content": "默认悬浮窗文本",
    "text_size": 11,
    "bg_color": "#CC000000",
    "text_color": "#FFFFFF",
    "x": 16,
    "y": 100,
    "passthrough": false,
    "survive_on_destroy": false,
    "show_on_start": false,
    "keep_last_state": false,
    "hide_in_service": false,
    "persistent": false
  },
  "inject_prompt": {
    "enabled": true,
    "content": "注入到系统提示词中的内容"
  },
  "instructions": [
    {
      "pattern": "<指令正则或固定文本>",
      "description": "指令功能描述",
      "handler": "js_handler_function_name",
      "dialog_html": "弹窗使用的 HTML 文件",
      "hide_in_ui": false
    }
  ]
}
```

### 3.1 字段详解

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `id` | 是 | `string` | 模块唯一标识，只能包含字母、数字、下划线。 |
| `name` | 是 | `string` | 用户可见的模块名称。 |
| `version` | 是 | `string` | 语义化版本号，如 `1.0.0`、`2.2.1`。 |
| `author` | 是 | `string` | 作者或组织名称。 |
| `description` | 是 | `string` | 模块功能简介，显示在模块市场或设置页。 |
| `type` | 是 | `string` | 模块分类，当前统一为 `TOOL`。 |
| `engine` | 否 | `string` | `hybrid` 或 `quickjs`。不填则默认为纯前端。 |
| `entry` | 否 | `string` | 前端入口 HTML 文件路径（`hybrid` 必填）。 |
| `js_entry` | 否 | `string` | 后端 QuickJS 入口脚本路径（`hybrid`/`quickjs` 必填）。 |
| `permissions` | 否 | `string[]` | 模块运行所需权限列表。 |
| `permissions_on_install` | 否 | `string[]` | 安装时立即申请的权限（通常是敏感权限）。 |
| `floating_window` | 否 | `object` | 悬浮窗默认配置，详见第 10 章。 |
| `inject_prompt` | 否 | `object` | 系统提示词注入配置，详见第 12 章。 |
| `instructions` | 否 | `object[]` | 自定义指令注册配置，详见第 11 章。 |

## 4. 权限系统

### 4.1 权限列表

Aiyu 平台采用**显式声明 + 动态申请**的权限模型。模块必须在 `manifest.json` 的 `permissions` 中声明所需权限，敏感权限还需在 `permissions_on_install` 中列出，以便在安装时向用户弹窗申请。

| 权限标识 | 权限名称 | 功能说明 |
|----------|----------|----------|
| `access_network` | 访问网络 | 模块可以向任意网络地址发起 HTTP 请求（如下载图片）。 |
| `write_chat_history` | 写入聊天记录 | 模块可以修改聊天记录，包括附加图片、替换消息内容、追加消息等。 |
| `register_instruction` | 注册自定义指令 | 模块可以注册自定义指令，匹配 AI 输出或用户输入后触发模块逻辑。 |
| `write_app_files` | 写入 APP 文件 | 模块可以写入、复制、移动或删除 APP 数据目录下的任意文件。 |
| `display_floating_window` | 显示悬浮窗 | 模块可以在屏幕上显示悬浮窗，实时展示状态信息。 |
| `inject_system_prompt` | 注入系统提示词 | 模块可以向系统提示词（System Prompt）中注入自定义内容，影响 AI 行为。 |

### 4.2 权限申请示例

#### 悬浮窗类模块（AI 宠物养成 / Token 查看器）

```json
{
  "permissions": ["display_floating_window"],
  "permissions_on_install": ["display_floating_window"]
}
```

#### 网络与文件操作类模块（图片下载器）

```json
{
  "permissions": [
    "access_network",
    "write_chat_history",
    "write_app_files",
    "register_instruction"
  ],
  "permissions_on_install": [
    "access_network",
    "write_app_files"
  ]
}
```

#### 提示词与指令类模块（爱心代码）

```json
{
  "permissions": [
    "inject_system_prompt",
    "register_instruction"
  ]
}
```

### 4.3 权限使用注意事项

1. **最小权限原则**：只申请业务必需的权限，避免过度申请导致用户拒绝安装。
2. **安装时申请**：`permissions_on_install` 中的权限会在模块安装/启用时弹窗请求，未授权的模块可能无法正常运行。
3. **运行时检测**：调用 Native API 前，建议通过相关 API（如 `isFloatingEnabled`）检测权限状态，避免异常崩溃。
4. **权限与功能绑定**：若用户关闭某项权限（如禁用悬浮窗），模块应优雅降级，保持其他功能可用。

## 5. 示例模块详解

### 5.1 AI 宠物养成（`ai_pet`）

| 属性 | 值 |
|------|-----|
| **模块名称** | AI 宠物养成 |
| **引擎模式** | `hybrid` |
| **核心功能** | 将用户与 AI 的对话 Token 消耗转化为宠物养成游戏。 |
| **权限** | `display_floating_window` |

**游戏机制**：
- 每次 `onTokenUpdate`（AI 回复后）触发经验计算。
- 基础经验 = `totalTokens / 10`（上限 500）。
- 动态加成：高效对话（completion/prompt ≥ 0.5）+30%，缓存命中 +10%，低效对话（ratio < 0.1 且 prompt > 500）-20%。
- 经验累积 → 升级 → 进化形态（蛋蛋 → 团子 → … → 龙龙 → 神龙）。
- 连续对话天数追踪、亲密度系统、成就系统、心情系统。

**关键文件**：
- `index.html`：宠物状态展示、进化路线、成就墙、历史记录、悬浮窗开关。
- `main.js`：`onTokenUpdate` 主处理器、经验计算、进化判定、成就检查。

## 6. 数据存储

### 6.1 模块独立 SharedPreferences（KV 存储）

Hybrid 与 QuickJS 模块均可通过 `AiyuNative.getModuleSetting(key, defaultValue)` 和 `AiyuNative.setModuleSetting(key, value)` 读写模块私有的键值对存储。所有值均为字符串，复杂对象需手动 `JSON.stringify`/`JSON.parse`。

**常用 Key 命名规范**：

| Key | 用途 | 示例模块 |
|-----|------|----------|
| `history` | 历史记录 JSON 数组 | Token 查看器、AI 宠物养成 |
| `history_archive` | 归档的历史摘要 | Token 查看器 |
| `daily_stats` | 按天聚合统计 | Token 查看器 |
| `total_*` | 累计统计（调用次数、Token、费用等） | Token 查看器 |
| `model_prices` | 模型价格表 JSON | Token 查看器 |
| `pet_exp` / `pet_level` / `pet_form` | 宠物经验、等级、形态 | AI 宠物养成 |
| `pet_achievements` | 成就列表 JSON | AI 宠物养成 |
| `context_size` | 上下文大小配置 | Token 查看器 |
| `week_start_mode` | 周起始模式（0=周日，1=周一） | Token 查看器 |

### 6.2 localStorage（前端页面间共享）

同一模块内的多个 HTML 页面（如配置页与动画页）若共享同一 Origin，可通过 `localStorage` 共享数据。

```javascript
// 写入
localStorage.setItem('heart_custom_text', 'I Love You');
// 读取
const text = localStorage.getItem('heart_custom_text') || 'I Love You';
```

> **注意**：`localStorage` 仅在纯前端或 Hybrid 模块的前端页面间有效，QuickJS 后端无法直接访问。

### 6.3 数据迁移与兼容

- **旧数据结构迁移**：读取配置时检测旧版扁平结构，自动迁移为新版嵌套结构（如 `daily_stats` 从 `{calls, tokens}` 迁移为 `{total:{...}, main:{...}}`）。
- **一次性重建**：通过标志位（如 `stats_rebuilt_v2`）防止重复执行数据重建逻辑。

## 7. 原生 API 接口参考

### 7.1 通用 API

#### `AiyuNative.log(message)`
输出日志到 Native 日志系统，便于调试。

```javascript
AiyuNative.log('[module_id] something happened');
```

#### `AiyuNative.getModuleSetting(key, defaultValue)` → `string`
读取模块配置值。返回值为 JSON 字符串（平台封装），通常结构为 `{"success": true, "value": "..."}`。

```javascript
var result = AiyuNative.getModuleSetting('pet_exp', '0');
var obj = JSON.parse(result);
var exp = obj.success ? obj.value : '0';
```

#### `AiyuNative.setModuleSetting(key, value)`
写入模块配置值。

```javascript
AiyuNative.setModuleSetting('pet_exp', String(newExp));
```

### 7.5 前端桥接封装

前端页面通过 `window.AiyuNative.call(method, paramsJsonString)` 调用 Native 方法。建议封装为 Promise：

```javascript
async function nativeCall(method, params) {
    return new Promise((resolve, reject) => {
        try {
            const result = window.AiyuNative.call(method, JSON.stringify(params || {}));
            resolve(JSON.parse(result));
        } catch (e) {
            reject(e);
        }
    });
}

// 使用示例
const r = await nativeCall('getModuleSetting', { key: 'pet_exp', default: '0' });
const exp = r.success ? r.value : '0';
```

## 8. 前端（HTML）开发规范

### 8.1 视觉规范

- **卡片容器**：使用 `border-radius: 20px`，背景色跟随系统主题（`var(--card-bg)`）。
- **设置行**：`padding: 16px`，最小高度 `48px`，Flex 布局左文右控件。
- **分割线**：`border-top: 1px solid var(--divider)`，左右边距 `16px`。
- **段标题**：`font-size: 18px; font-weight: bold; padding-left: 4px; margin-top: 24px; margin-bottom: 10px`。
- **描述文字**：`font-size: 13px; color: var(--text-desc);`。

### 8.2 深色模式适配

完全通过 CSS 媒体查询 `prefers-color-scheme` 实现，不依赖 Native 注入主题变量：

```css
:root {
    --bg: #EDEDED;
    --card-bg: #FFFFFF;
    --text: #000000;
    --text-desc: #999999;
    --divider: #E0E0E0;
    --primary: #EEA2AD;
}
@media (prefers-color-scheme: dark) {
    :root {
        --bg: #111111;
        --card-bg: #1E1E1E;
        --text: #FFFFFF;
        --text-desc: #AAAAAA;
        --divider: #3A3A3A;
        --primary: #EEA2AD;
    }
}
```

### 8.3 交互规范

- **开关（Switch）**：自定义滑动开关，宽度 `44px`，高度 `24px`。
- **按钮**：透明背景 + 主色文字，激活态 `opacity: 0.5`。
- **Toast**：底部居中，黑底白字，圆角 `24px`，自动隐藏。
- **弹窗**：底部 Sheet 或居中 Modal，遮罩层 `rgba(0,0,0,0.4)`。

### 8.4 安全规范

- **XSS 防护**：所有用户输入或动态渲染的内容必须经过转义：
  ```javascript
  function escapeHtml(s) {
      return String(s).replace(/&/g, '&amp;')
                      .replace(/</g, '&lt;')
                      .replace(/>/g, '&gt;');
  }
  ```
- **属性转义**：`replace(/"/g, '&quot;')` 用于 HTML 属性。

## 9. 后端（QuickJS）开发规范

### 9.1 入口函数

#### `onTokenUpdate(promptTokens, completionTokens, totalTokens, cachedTokens, modelName, apiCallType, source)`

**触发时机**：每次 AI 回复收到 Token 用量通知后调用。  
**返回值**：`string`，用于更新悬浮窗内容（若模块启用悬浮窗）。

**参数说明**：

| 参数 | 类型 | 说明 |
|------|------|------|
| `promptTokens` | `number` | 输入 Token 数。 |
| `completionTokens` | `number` | 输出 Token 数。 |
| `totalTokens` | `number` | 总 Token 数。 |
| `cachedTokens` | `number` | 缓存命中 Token 数（部分 API 返回，可能为 0）。 |
| `modelName` | `string` | 模型名（新版 APP 传入；旧版可能为空）。 |
| `apiCallType` | `string` | 调用类型：`chat`、`summary`、`interrupted`、`interrupted_no_usage`。 |
| `source` | `string` | 来源：`main`（聊天页）、`ilink`（微信）、`ext`（外部访问）。 |

**旧版 APP 兼容**：
- 旧版（v2.9.0 及以下）可能只传前 4 个参数，后 3 个为 `undefined`。
- 需通过 `resolveModelName()` 兜底链获取模型名：传入值 → `getCurrentModelName()` → 用户手填 fallback。
- `apiCallType` 默认 `'chat'`，`source` 默认 `'main'`。

### 9.2 工具函数模板

```javascript
// 安全 JSON 解析
function safeParse(str, fallback) {
    try { return JSON.parse(str); } catch (e) { return fallback; }
}

// 读取设置（自动解包 Native 返回结构）
function getSetting(key, defaultValue) {
    var result = AiyuNative.getModuleSetting(key, defaultValue);
    var obj = safeParse(result, {});
    if (obj && obj.success && obj.value !== undefined) return obj.value;
    return defaultValue;
}

// 保存设置
function setSetting(key, value) {
    AiyuNative.setModuleSetting(key, value);
}

// 日期格式化 YYYY-MM-DD
function formatDateYMD(d) {
    var y = d.getFullYear();
    var m = String(d.getMonth() + 1).padStart(2, '0');
    var day = String(d.getDate()).padStart(2, '0');
    return y + '-' + m + '-' + day;
}
```

### 9.3 错误处理

- 每个独立的写入操作应包裹在 `try-catch` 中，防止一处异常中断后续逻辑：
  ```javascript
  try {
      appendToDailyStats(...);
  } catch (e) {
      AiyuNative.log('[module] ERROR appendToDailyStats: ' + e.message);
  }
  ```

### 10.3 行为组合

| 行为 | `survive_on_destroy` | `persistent` | `hide_in_service` |
|------|----------------------|--------------|-------------------|
| 立即隐藏 | `false` | `false` | — |
| 仅退到后台时保留 | `false` | `true` | — |
| 始终保留 | `true` | `false` | — |
| 仅聊天页显示 | — | — | `true` |

## 13. 最佳实践与注意事项

### 13.1 性能

- **悬浮窗更新**：`onTokenUpdate` 返回值直接驱动悬浮窗，避免耗时操作阻塞 UI。
- **历史记录限制**：不限制条数时，需定期归档（如 30 天前的记录转存为按天摘要），防止 JSON 过大导致解析卡顿。
- **粒子/动画**：前端动画使用 `will-change`、`transform` 等 GPU 加速属性，控制同时存在的 DOM 节点数量（如最多 40 个粒子）。

### 13.2 兼容性

- **新旧 APP 适配**：检测 `arguments.length` 或尝试调用新 API（如 `getCurrentModelName`），失败时 catch 异常并回退到旧逻辑。
- **数据结构迁移**：读取配置时检查旧版字段，自动迁移到新结构，并使用标志位防止重复迁移。
- **API 缺失兜底**：前端调用 Native API 前，先用 `try-catch` 探测方法是否存在。

### 13.3 安全

- **输入校验**：所有从 Native 或用户输入读取的数值，使用 `Number()` 或 `parseInt` 转换，并设置合理上下限。
- **XSS 防护**：任何动态插入 HTML 的内容必须经过 `escapeHtml` 转义。
- **路径安全**：下载文件时，对 URL 提取的文件名做校验，防止路径遍历（`../`）。

### 13.4 调试

- 统一使用 `AiyuNative.log('[module_id] message')` 输出日志，便于通过 Native 日志工具抓取。
- 关键路径（经验计算、费用计算、进化判定）打印详细参数，方便线上问题定位。

### 13.5 版本管理

- 语义化版本号：`主版本.次版本.修订号`。
- 重大结构调整（如 `daily_stats` 格式变更）时，通过一次性重建脚本兼容旧数据，并用版本标志位（如 `stats_rebuilt_v2`）防止重复执行。
